# תמלול בלשכה

המתמלל הוא **ivrit.ai** (המודל שמאחורי הבוט "אליעזר" / ‎@BenYehudaBot) שרץ מקומית בלשכה, בתוך
האפליקציה `apitools` — קונטיינר `apitools-asr` על הפורט 8987. אין ענן, אין מפתח, ואודיו לא יוצא
מהלשכה.

## הזרימה של הודעה קולית שנשלחת אליך

קובץ שמצורף לשיחה נשמר אצלך בנתיב `…/attachments/v1/files/<xx>/<sha>/<name>` — אתה כבר רואה אותו
בהודעה. תמלל אותו ישירות:

```bash
curl -s -X POST http://apitools-asr:8987/transcribe \
     -F file=@"<הנתיב של הקובץ>" -F language=he -F response_format=json
# → {"text": "…"}
```

לטקסט עם זמנים ולכל מילה בנפרד (מה שצריך לעריכה, לכתוביות או לציטוט מדויק):

```bash
curl -s -X POST http://apitools-asr:8987/transcribe \
     -F file=@"<הנתיב>" -F language=he -F response_format=verbose_json
```

## הקלטה ארוכה / וידאו

מעל ~2 דקות זה **עבודה בתור**, לא בקשה חיה. בקש מזהה עבודה ושאל אותו:

```bash
curl -s -X POST 'http://apitools-asr:8987/transcribe?async=1' \
     -F file=@"<הנתיב>" -F language=he            # → 202 {id, status, …}
curl -s "http://apitools-asr:8987/transcriptionStatus?id=<id>"    # progress באחוזים ובשניות אודיו
curl -s "http://apitools-asr:8987/v1/audio/transcriptions/<id>/vtt"   # vtt | srt | txt | docx | json | verbose_json
```

- **קצב אמיתי בלשכה:** פי ~3 איטי מזמן אמת בדיבור צפוף (דקת אודיו ≈ 3 דקות עיבוד), קרוב לזמן אמת
  בהודעה קולית עם הפסקות. עבודה אחת בכל רגע. 300 שניות בלי עבודות — המודל משתחרר מהזיכרון, והעבודה
  הבאה משלמת 10–16 שניות טעינה. **אל תבטיח תמלול מיידי**: אמור שהעבודה נכנסה לתור, וחזור עם התוצאה.
- **תקרות:** עד 4 שעות / 3GB לקובץ (השירות מסרב עם המספר, לא חותך בשקט), תור של 8 — תור מלא מחזיר
  `429` עם `Retry-After`, וזה לא באג. קבצים נשמרים לפי TTL ומוחזרים מחדש מאותה עבודה בלי לרוץ שוב.
- **מה אין:** דיאריזציה (מי דיבר) — אין חומרה לכך בלשכה; תמלול חי בזמן אמת — טרם נבנה. אל תציע אותם.

## איך מחזירים תמלול

1. **התמלול עצמו הוא התוצר** — הצג אותו (או שמור אותו כקובץ deliverable כשמדובר בהקלטה ארוכה), ורק
   אחר כך הוסף שורה או שתיים של סיכום אם ביקשו. אל תכתוב סיכום *במקום* התמלול.
2. Hebrew, RTL, בלי `direction` אם זה טקסט רגיל; מספרים/שמות קבצים בתוך טקסט עברי — עם `isolate`.
3. אם התמלול נשמע שגוי במקום מסוים (שם, מספר, מונח), אמור זאת במפורש במקום לתקן בשקט.
4. לתמלול שצריך להישמר — שמור אותו כקובץ (`.txt`/`.vtt`/`.docx`) והצג אותו; זה מה שנשאר לבעל הלשכה.

## עריכה

התמלול נשמר כאובייקט קנוני (קטעים, מילים, זמנים, גרסה) ו-`vtt`/`srt`/`docx` הם **תצוגות** שלו.
תיקון של בעל הלשכה הוא עריכה של האובייקט — לא של הייצוא — כדי שכל פורמט ימשיך לצאת נכון.
