# synth-demo-docs

Fully **synthetic** document corpus, same layout as `demo-docs/`, generated by the apitools doc-gen API (`src/doc_gen`) from typed data models (`src/doc_models`).

Each document is realistic Israeli-business-grade (logo, מסמך ממוחשב, מקור, allocation number, Instruction-36 footer) and **its model is its own ground truth** — see `truth.json` (`documents[].truth` = the exact extraction contract each doc yields).

Regenerate: `python3 scripts/gen_synth_corpus.py <out>` inside the apitools container.
