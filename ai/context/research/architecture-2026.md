# DGO — world-leading public software architecture 2026 (research synthesis)

Date 2026-10-14. Sources: six parallel researchers plus direct fetches of primary pages; the search budget ran out mid-task, so later facts come only from fetched pages. Convention: each claim ends with (URL, date); a URL **without a date** means the page shows none and was accessed 2026-10-14.

## 0. Trend anchors, registry format, supply chain (cross-cutting)

- InfoQ: agentic AI and privacy engineering are "innovator", platform/socio-technical architecture "early adopter" (https://www.infoq.com/articles/architecture-trends-2025/, 2025-04-28). Thoughtworks Radar vol. 34: **Passkeys = Adopt** (https://www.thoughtworks.com/radar, 2026-04).
- Registry format: `docker compose publish` stores a Compose app as an OCI artifact, run via `-f oci://…`; refuses build-only services and local `include`, runs a secret detector, confirms interpolation and remote includes at run time (https://docs.docker.com/compose/how-tos/oci-artifact/); a regular command since v2.34.0 (https://github.com/docker/compose/releases/tag/v2.34.0, 2025-03-14).- Signing/updates: cosign `sign-blob --bundle` = signature, certificate and transparency proof in one file (https://docs.sigstore.dev/cosign/signing/signing_with_blobs/); go-tuf v2 keeps updates safe "even against attackers that compromise the repository or signing keys" (https://github.com/theupdateframework/go-tuf); GoReleaser notarizes macOS binaries from Linux CI since v2.1 (https://goreleaser.com/customization/notarize/, 2026-08-13).
- Go: 1.25 container-aware `GOMAXPROCS` and `FlightRecorder` (https://go.dev/doc/go1.25, 2025-08); 1.26 Green Tea GC default (10–40 % less GC overhead), cgo −30 %, post-quantum TLS default (https://go.dev/doc/go1.26, 2026-02).
**Adopt / avoid:** Publish DGO app packages as Compose-spec OCI artifacts (one registry serves images and manifests), signed with cosign bundles under a TUF root the `dgo` updater verifies; build on Go ≥1.26 with GoReleaser. Avoid a bespoke registry protocol and unsigned moving tags.

## 1. Product precedents (self-hosted platform-OS with app stores)

- **Umbrel** (2.0 shipped 2026-09-22, https://api.umbrel.com/latest-release): `umbrel-app.yml` (`manifestVersion` 2.0, store-unique `port`, `storage.dataRoot`, `dependencies`, `backupIgnore`, `permissions`), env-only `app_proxy` (`APP_HOST=<app>_<svc>_1`, `PROXY_AUTH_*`), lifecycle `hooks/`, every image `tag@sha256` multi-arch, no `build:`, no Docker socket (https://raw.githubusercontent.com/getumbrel/umbrel-apps/master/.agents/skills/umbrel-package-app/SKILL.md); community stores = a repo whose id prefixes every app (https://github.com/exabird/umbrel-community-app-store). Wrong: auto-backups with no schedule and invisible failures (https://community.umbrel.com/t/introducing-backups-on-umbrelos/23961, 2025-09-23); 1.6 Pro-only (https://community.umbrel.com/t/introducing-umbrelos-1-7/25014.md, 2026-04-21).
- **CasaOS**: compose + top-level `x-casaos` (`main`, `architectures`, `port_map`, localized copy) (https://raw.githubusercontent.com/IceWhaleTech/CasaOS-AppStore/main/docs/specs/compose-and-x-casaos.md); store v2 = static `index.json` + `content_hash` (https://raw.githubusercontent.com/IceWhaleTech/CasaOS-AppStore/main/docs/migration/overview.md). Wrong: core frozen at v0.4.15 (https://github.com/IceWhaleTech/CasaOS/releases, 2024-12-19).
- **Coolify** (v4.0.0 after ~2 years of beta, https://github.com/coollabsio/coolify/releases/tag/v4.0.0, 2026-04-27): compose templates with magic `SERVICE_*` vars that "Coolify does not merge future template changes into" (https://coolify.io/docs/services/configuration/docker-compose); forward-only self-update, downgrade = "restore the backup" (https://coolify.io/docs/core/instance-management/downgrade). Wrong: command injection CVE-2025-22605 (https://cveawg.mitre.org/api/cve/CVE-2025-22605); root RCE via proxy-config filename (https://vuln.today/cve/CVE-2025-66212, 2025-12-23).
- **Dokploy**: `blueprints/<id>/{docker-compose.yml,template.toml,meta.json}`, `${password:32}` helpers, `expose` not `ports` (https://github.com/Dokploy/templates); Traefik + Swarm (https://github.com/Dokploy/dokploy). Wrong: path-traversal RCE, CVSS 9.9 (https://nvd.nist.gov/vuln/detail/CVE-2026-45661); shell built from template literals while an escape helper sat unused (https://github.com/Dokploy/dokploy/security/advisories/GHSA-3frc-cfh9-ch2c, 2026-05-11).
- **YunoHost**: `manifest.toml` v2 — `[integration]` ldap/sso/architectures, typed `[install]` questions, `[resources]` provisioning (system_user, install_dir, permissions, apt, database, ports, sources with sha256) (https://raw.githubusercontent.com/YunoHost/example_ynh/master/manifest.toml); one `apps.toml` catalog, quality `level` set only by CI (https://raw.githubusercontent.com/YunoHost/apps/master/README.md). Wrong: 12.0 SSO rework broke Basic-Auth apps (https://forum.yunohost.org/t/yunohost-12-0-bookworm-release-sortie-de-yunohost-12-0-bookworm/31673, 2024-10-31).
- **TrueNAS SCALE**: k3s/Helm → Compose because "Helm charts are powerful, but they are more complex and less portable" and "K3s and Helm charts have been too complex and less reliable" (https://forums.truenas.com/t/the-future-of-electric-eel-and-apps/5409, 2024-05-29); `app.yaml` + `questions.yaml` + `app_migrations.yaml` (https://github.com/truenas/apps/blob/master/CONTRIBUTIONS.md). Wrong: migration blockers (encrypted pools, clone dependencies, no IPv6) and a hard cutoff (http://www.truenas.com/docs/scale/24.10/gettingstarted/scalereleasenotes/).
- **Home Assistant**: `config.yaml` with `ingress`, read-only `map`, `backup: hot|cold`, `watchdog`, `breaking_versions`, typed options schema; add-ons renamed "apps" (https://developers.home-assistant.io/docs/add-ons/configuration/); per-app security score + Cosign-signed images (https://developers.home-assistant.io/docs/add-ons/security). Wrong: 2025.1 forced backup encryption and dropped backup-before-update, reverted in 2025.2 (https://www.home-assistant.io/blog/2025/02/05/release-20252/, 2025-02-05); Supervisor auth bypass present since 2017 (https://www.home-assistant.io/blog/2023/03/08/supervisor-security-disclosure/, 2023-03-08).
- **Nextcloud**: only Featured apps must be signed (https://docs.nextcloud.com/server/stable/developer_manual/app_publishing_maintenance/code_signing.html); ExApps = any-language containers; HaRP outbound tunnel recommended, Docker Socket Proxy removed in NC 35 (https://github.com/nextcloud/app_api). Wrong: HaRP certificates never renewed (https://github.com/nextcloud/HaRP).
- **Sandstorm**: grain per document, one Cap'n Proto socket, Powerbox capability grants (https://sandstorm.io/how-it-works); founder: "wouldn't recommend running it in its current state" (https://hn.svelte.dev/item/44844394, 2025).
- **Cosmos Cloud**: one Go binary = proxy + auth + container manager, needs the Docker socket, Commons Clause (https://github.com/azukaar/Cosmos-Server); auto-update only on floating tags (https://cosmos-cloud.io/docs/servapps/).
- **Runtipi**: `x-runtipi` compose, Traefik labels generated (https://runtipi.io/docs/reference/dynamic-compose); v4.10.2 pulls before stopping and rolls back (https://github.com/runtipi/runtipi/releases); v4.0.0 renamed every local domain and path (https://runtipi.io/docs/reference/breaking-updates).

Cross-cutting failures: shell strings as the control-plane API (Coolify, Dokploy); forward-only updates with no rollback (Coolify, Umbrel); drifting templates (Coolify); the Docker socket as app API (Cosmos, Nextcloud, HA); trust-by-tag updates (Cosmos); catalogs that die with the vendor's pivot (CasaOS, Umbrel Pro, Sandstorm).

**Adopt / avoid:** Adopt Umbrel's digest-pinned multi-arch images with explicit port/data-root/hooks; HA's `backup: hot|cold`, `watchdog`, `breaking_versions` and visible security score; YunoHost's typed install questions and CI-computed levels; TrueNAS's `app_migrations`; Runtipi's pull-before-stop rollback; CasaOS-v2's static signed index. Avoid any exec of interpolated shell in the core (argv only), the Docker socket as an app API, floating-tag updates, renaming routes in a major, and auth as a proxy flag instead of a declared, compiler-enforced manifest capability.

## 2. Declarative state + reconciler

- Kubernetes: `spec` = desired, `status` = "most recent observations of actual state", `observedGeneration`, "level-based rather than edge-based" (https://github.com/kubernetes/community/blob/master/contributors/devel/sig-architecture/api-conventions.md). `metav1.Condition` (KEP-1623, GA 1.19): CamelCase `type`, `status` True|False|Unknown, `observedGeneration`, required `lastTransitionTime` and `reason` (https://github.com/kubernetes/enhancements/tree/master/keps/sig-api-machinery/1623-standardize-conditions). Finalizers: `deletionTimestamp` → Terminating until every controller removes its key (https://kubernetes.io/docs/concepts/overview/working-with-objects/finalizers/).
- Flux Kustomization is the single-object reconciler to copy: `interval`, `retryInterval`, `timeout`, inventory `prune`, `wait`/`healthChecks`, `suspend`, `dependsOn`, server-side dry-run each interval = drift detection; manual edits "promptly reverted" (https://fluxcd.io/flux/components/kustomize/kustomizations/).
- NixOS: `switch|boot|test|dry-activate|--rollback`, numbered generations listed by the bootloader; `nixos-rebuild-ng` default in 25.11 (https://wiki.nixos.org/wiki/Nixos-rebuild, 2026-06-30).- Ignition: runs once, in the initramfs on first boot; JSON spec v3.6.0 or Butane YAML (https://coreos.github.io/ignition/).
- Terraform `plan`: `-refresh-only` records out-of-band drift; `-out` plan files applied verbatim and cleartext-sensitive; `-detailed-exitcode` 0/1/2; `-json`; `-target` "not recommended for routine operations" (https://developer.hashicorp.com/terraform/cli/commands/plan).
- Compose as the rendered layer: open spec implemented by Compose, Kompose, nerdctl, Podman Compose (https://github.com/compose-spec/compose-spec/blob/main/GOVERNANCE.md); Compose v5.2.0 added an explicit "reconciliation plan between observed and expected state", v5.5.0 image-digest reconciliation (https://github.com/docker/compose/releases, 2026-06-23).
**Adopt / avoid:** Adopt the Kubernetes/Flux vocabulary literally — `generation`/`observedGeneration`, Condition-shaped status with a `Ready` summary, level-triggered converge-to-latest, inventory `prune`, finalizer-guarded teardown, `plan -out` as a signed artifact that `apply` executes verbatim, `-refresh-only` drift reports with exit code 2 = changes pending, NixOS-style generations with `switch|boot|test|--rollback`. Avoid edge-triggered on-change hooks, partial `-target` applies, image-tag polling, and a manifest dialect of your own.

## 3. Networking for multi-office

- WireGuard: Cryptokey Routing (public key ↔ AllowedIPs = routing table outbound, ACL inbound), roaming endpoints, key distribution "out of scope" (https://www.wireguard.com/). wireguard-go `tun/netstack` (gVisor) = in-process Dial/Listen with no TUN device (https://pkg.go.dev/golang.zx2c4.com/wireguard/tun/netstack, 2022-07-03). tsnet embeds a full node without root: `Server{Hostname, AuthKey, Dir, ControlURL}`, `Listen/ListenTLS/ListenService/Dial`, `LocalClient().WhoIs` identifies callers (https://pkg.go.dev/tailscale.com/tsnet, 2026-10-07).
- Tailscale: the coordination server is a key directory + policy store carrying "virtually no traffic"; STUN/ICE with DERP relays over HTTPS as fallback (https://tailscale.com/blog/how-tailscale-works, 2020-03-20). DERP "blindly forwards already-encrypted traffic" (https://tailscale.com/kb/1232/derp-servers, 2026-01-21); peer relays GA — any node relays for its tailnet before DERP (https://tailscale.com/kb/1591/peer-relays, 2026-02-04); tailnet lock = node keys must be signed by trusted signing keys, so a compromised control plane cannot admit nodes (https://tailscale.com/kb/1226/tailnet-lock).
- Headscale ("self-hosters and hobbyists", one tailnet): MagicDNS, ACL/grants, embedded DERP, peer relays, subnet/exit nodes, SSH; OIDC groups unusable in ACLs; Funnel/Serve open (https://headscale.net/stable/about/features/); 0.29.0 adds grants, min client 1.80; upgrade one minor at a time, no downgrade (https://github.com/juanfont/headscale/blob/main/CHANGELOG.md, 2026-06-17).
- NetBird: Management + Signal (stores nothing) + Relay (Coturn → WebSocket relay since v0.29.0), WireGuard end-to-end, all self-hostable (https://docs.netbird.io/about-netbird/how-netbird-works, 2026-10-05). Nebula: the certificate is the identity (IP, name, groups) from your own CA, firewall by cert groups (https://nebula.defined.net/docs/guides/quick-start/). innernet: CIDR associations as ACL, no hole punching, "has not received an independent security audit" (https://github.com/tonarino/innernet). ZeroTier: "Private moons are deprecated" (https://docs.zerotier.com/zerotier/moons).

**Adopt / avoid:** Adopt what every survivor converged on: a per-machine WireGuard key is the device identity, access is a signed policy over tags/`svc:` names, discovery is tunnel-scoped DNS per machine and per service. For a solo vendor: point-to-point WireGuard as the base, the node embedded in `dgo` via wireguard-go/netstack (or tsnet against a self-hosted Headscale), an encrypted relay fallback any office can host, and a tailnet-lock rule that no coordination server can admit a node alone. Avoid vendor roots, a TURN fleet before P2P + one relay fails, and unaudited meshes as the trust anchor.

## 4. Identity

- Minimal Go IdPs: Pocket ID — passkey-only, OIDC Certified, SQLite by default, single binary, BSD-2, v2.18.0 adds SCIM/LDAP sync (https://github.com/pocket-id/pocket-id/releases, 2026-10-04). Ory Hydra — headless OP, binaries "5-15MB", v26.2.0 with SQLite builds (https://github.com/ory/hydra/releases, 2026-03-20). Zitadel — Postgres-only, AGPL-3 with exceptions, "approximately 512MB of RAM" (https://zitadel.com/docs/self-hosting/manage/production). Authelia — Go forward-auth companion, <20 MB image, <30 MB RAM, OIDC Certified (https://www.authelia.com/blog/we-are-now-openid-certified/, 2025-05-18).- Passkeys: WebAuthn Level 3 is a W3C Recommendation — related origins, hints, backup-state flags, PRF, largeBlob, `getClientCapabilities()` (https://www.w3.org/TR/webauthn-3/, 2026-08-25). Related Origin Requests: `/.well-known/webauthn`, at most 5 labels, "designed to be used when federation is not possible" (https://passkeys.dev/docs/advanced/related-origins/, 2026-02-05). Synced passkeys on Android 9+/iOS 16+/macOS 13+; Windows still device-bound (https://passkeys.dev/device-support/, 2026-09-21).
- Forward-auth: Traefik v3.7 ForwardAuth — 2XX passes; `trustForwardHeader` deprecated for `forwardedHeaders.trustedIPs`; set `maxBodySize`/`maxResponseBodySize`; `forwardBody` breaks streaming (https://doc.traefik.io/traefik/reference/routing-configuration/http/middlewares/forwardauth/). 2026 bypasses: X-Forwarded-Prefix, CVSS 10.0, fixed 3.6.14 (https://corgea.com/advisories/vulnerabilities/CVE-2026-35051, 2026-04-24); X-Forwarded-Port, fixed 3.7.6 (https://app.opencve.io/cve/CVE-2026-54764, 2026-07-06). Caddy `forward_auth` = `reverse_proxy` + `handle_response @2xx` + `copy_headers Remote-User` (https://caddyserver.com/docs/caddyfile/directives/forward_auth); CVE-2026-30851: a client-supplied header of the same name was never deleted → identity injection, fixed 2.11.2 (https://corgea.com/advisories/vulnerabilities/CVE-2026-30851, 2026-03-06).- Federation for a link: OpenID Federation 1.0 is Final — signed entity configurations, trust anchors, trust chains (https://openid.net/specs/openid-federation-1_0.html, 2026-02-17); JWT BCP revision: validate `aud`, explicit `typ`, treat `kid`/`jku`/`x5u` as attacker input (https://datatracker.ietf.org/doc/draft-ietf-oauth-rfc8725bis/, 2026-08-21); SPIFFE federation = bundle endpoints with a one-time manual bundle exchange (https://spiffe.io/docs/latest/architecture/federation/readme/).

**Adopt / avoid:** Per-office IdP (sovereignty, works offline) with pairwise trust: the link door verifies the peer's JWS with pinned `iss`/`aud`/`alg`/`typ`, JWKS fetched only inside the tunnel, two-key overlap rotation — OpenID-Federation-shaped entity statements, with the WireGuard key as SVID-grade machine identity. Pocket ID or Hydra+Kratos fit the footprint; passkeys first with a fallback while Windows passkeys stay device-bound. Prefer OIDC per app; where forward-auth is unavoidable strip Remote-*/X-Forwarded-* at the edge, run Traefik ≥3.7.6, bind apps to the proxy's address. Avoid a central vendor IdP and SPIRE for two offices.

## 5. API + CLI

- Frameworks: Cobra v1.10.2, 195,884 importers; the pflag rename in 1.10.0 broke builds (https://pkg.go.dev/github.com/spf13/cobra, 2025-12-03); urfave/cli v3.14.0, generics, four-shell completion (https://pkg.go.dev/github.com/urfave/cli/v3, 2026-10-02).
- Output: clig.dev — `--json`/`--plain` for scripts, data to stdout and logs to stderr, mapped exit codes, colour off when not a TTY or `NO_COLOR`, "Keep changes additive" (https://clig.dev/); gh `--json <fields>` + `--jq`, exit codes 0/1/2/4 (https://cli.github.com/manual/gh_help_exit-codes).
- Versioned contracts: Docker negotiates the highest common API version, `DOCKER_API_VERSION` pins; 28.x = API 1.48–1.51 min 1.24, 29.x = 1.52–1.56 min 1.44 (1.40 from 29.3) — the Traefik-3.3 breakage in CLAUDE.md is exactly this floor (https://docs.docker.com/reference/api/engine/; https://www.docker.com/blog/docker-engine-version-29/, 2025-11-11).- API style: ConnectRPC — one `net/http` handler speaks Connect (plain JSON POST, curl-able, HTTP/1.1–3, streaming), gRPC and gRPC-Web; CNCF sandbox; connect-go v2 with v1 supported indefinitely (https://connectrpc.com/docs/introduction; https://github.com/connectrpc/connect-go/releases, 2026-10-14).
- Local control sockets: dockerd `unix:///var/run/docker.sock`, TCP "un-encrypted and un-authenticated" (https://docs.docker.com/reference/cli/dockerd/); Tailscale `safesocket` = Unix socket or Windows named pipe with peer credentials, macOS sandbox falls back to localhost + token (https://pkg.go.dev/tailscale.com@v1.90.6/safesocket, 2025-10-31).
- One binary = CLI + daemon + UI: Tailscale `tailscaled` + `tailscale`; `//go:embed` for assets (https://pkg.go.dev/embed); kardianos/service v1.3.0 installs Windows/launchd/systemd/OpenRC from one binary, `Dependencies` unimplemented on Linux/launchd (https://github.com/kardianos/service, 2026-07-06).

**Adopt / avoid:** Cobra with a `--json`/`--plain` contract carrying an explicit `apiVersion`, NO_COLOR/TTY detection, gh-style exit codes; the `dgo` daemon as ConnectRPC over a peer-credential Unix socket (named pipe on Windows, token fallback where the OS forces TCP), Docker-style version negotiation, console embedded with `go:embed`, service install via kardianos/service. Avoid "format may change" JSON, gRPC-only APIs the browser console cannot call, unauthenticated TCP control ports.

## 6. UI

- Shells: Puter — AGPL-3, App Store, per-app sandboxed storage, `puter.ui.createWindow` (https://docs.puter.com/UI/createWindow/); daedalOS — react-rnd windows persisting geometry, MIT (https://github.com/DustinBrett/daedalOS).
- Embedding: iframe `sandbox` is an allow-list; `allow-scripts` + `allow-same-origin` on same-origin content lets a frame strip its own sandbox (https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe, 2026-10-01). CSP `frame-ancestors` (header only) supersedes `X-Frame-Options` (https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors, 2026-08-27). CHIPS `Partitioned` cookies (`Secure`, `__Host-` recommended) in Chrome/Edge 114, Firefox 141, Safari 26.2 (https://privacysandbox.google.com/cookies/chips, 2023-12-15). Module Federation 2.0: bundler-independent runtime, `mf-manifest.json`, runtime plugins (https://module-federation.io/blog/announcement.html, 2024-04-26).
- PWA: installable = manifest + 192/512 icons + HTTPS; `beforeinstallprompt` is Chromium-only and absent on iOS; iOS 16.4+ installs via the Share sheet (https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable, 2026-10-06).
- RTL: logical properties (`margin-inline-start`, `inset-inline`, `inline-size`, `text-align: start`) (https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_logical_properties_and_values, 2025-11-18); W3C Hebrew gap analysis: logical shorthands weakly supported, diacritic colouring and maqaf selection open (https://www.w3.org/TR/hebr-gap/, 2025-05-31); mirror directional icons/steppers/pagination, never clocks, checkmarks, media controls, numbers, charts (https://doc.wikimedia.org/codex/v1.18.0/style-guide/bidirectionality.html).
- Tokens: DTCG Format 2025.10 Final CG Report — `$value/$type/$description/$extensions/$deprecated`, `{alias}` + JSON-Pointer `$ref`, composites, `.tokens.json`; "not a W3C Standard nor on the Standards Track" (https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/, 2025-10-28). Style Dictionary: DTCG first-class since v4, full 2025.10 "work in progress for v5", latest v5.6.1 (https://styledictionary.com/info/dtcg/).
- Accessibility: WCAG 2.2 Recommendation — Focus Not Obscured, Dragging Movements, Target Size 24×24, Consistent Help, Redundant Entry, Accessible Authentication; 4.1.1 removed (https://www.w3.org/TR/WCAG22/, 2024-12-12); EN 301 549 V4.1.1 adopts WCAG 2.2 AA (https://nda.ie/news/en301549-published, 2026-09). APG has no "window" pattern: modal dialog (`aria-modal`, focus trap, Esc, focus return) + Window Splitter for pane handles (https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).

**Adopt / avoid:** Keep iframes behind one origin (Traefik host routing) as the app boundary — cookies stay first-party and no CHIPS/Storage-Access prompts arise; every app answers `frame-ancestors 'self' <console-origin>`, third-party tiles get `sandbox="allow-scripts allow-forms allow-popups"` and never `allow-same-origin` on same-origin content, postMessage with exact origins. Module Federation only for first-party tiles, never for n8n/Plane. Publish Olive Grove as a DTCG 2025.10 `.tokens.json` compiled by Style Dictionary v5 into theme-tokens.css (G27/G82 unchanged). Window chrome: APG dialog semantics, Window Splitter, 24×24 targets — WCAG 2.2 AA is now the EN 301 549 baseline. PWA: manifest + icons, Share-sheet guidance on iOS, never wait for `beforeinstallprompt`.

## 7. OS / services / the any-OS base

- systemd: `Type=notify`/`notify-reload` over `NOTIFY_SOCKET` (`READY=1`, `RELOADING=1` + `MONOTONIC_USEC`, `STOPPING=1`, `WATCHDOG=1`, `EXTEND_TIMEOUT_USEC=`), stable and reimplementable without libsystemd (https://man7.org/linux/man-pages/man3/sd_notify.3.html, 2026-08-04); `systemd-analyze security --threshold` scores exposure 0–10 over `ProtectSystem=strict`, `NoNewPrivileges`, `SystemCallFilter=@system-service`, `RestrictAddressFamilies`, `DynamicUser`, `StateDirectory` (https://man7.org/linux/man-pages/man1/systemd-analyze.1.html).
- launchd: LaunchDaemons (root, boot) vs LaunchAgents (login); the process must not fork; prefer `Sockets` on-demand over `KeepAlive`; modern `launchctl bootstrap|bootout|kickstart -k`, `load|unload` are legacy (https://keith.github.io/xcode-man-pages/launchctl.1.html, 2014-10-01).
- Windows: a service exe must implement the SCM handshake — a console exe cannot simply be registered (https://learn.microsoft.com/en-us/windows/win32/services/service-programs, 2025-04-15); Go `svc.Run`/`IsWindowsService`/`mgr` (https://pkg.go.dev/golang.org/x/sys/windows/svc, 2026-10-06).
- WSL2: open-sourced — wsl.exe, wslservice, init, gns, plan9; lxcore.sys stays closed (https://blogs.windows.com/windowsdeveloper/2025/05/19/the-windows-subsystem-for-linux-is-now-open-source/, 2025-05-19). `.wslconfig`: `networkingMode=mirrored` (Win11 22H2+: localhost both ways, IPv6, LAN, VPN; Hyper-V firewall rule needed), `vmIdleTimeout` 60 s, `autoMemoryReclaim=gradual` (https://learn.microsoft.com/en-us/windows/wsl/wsl-config, 2026-04-15; https://learn.microsoft.com/en-us/windows/wsl/networking, 2026-06-02); `wsl.conf [boot] systemd=true`, yet "systemd services will NOT keep your WSL instance alive" (https://learn.microsoft.com/en-us/windows/wsl/systemd, 2025-01-13). Own distro: `.wsl` tar + `/etc/wsl-distribution.conf`, `wsl --install --from-file` (https://learn.microsoft.com/en-us/windows/wsl/build-custom-distro, 2025-09-12).
- Lima: VZ default since v1.0 on macOS 13.5+, vmType fixed at create (https://lima-vm.io/docs/config/vmtype/, 2026-10-05). Apple `container`: one lightweight VM per Linux container, OCI images, Apple silicon + macOS 26 only, no Compose (https://github.com/apple/container/releases).
- Engines: Docker 28 vs 29 API floor (§5); rootless Docker needs newuidmap + 65,536 subordinate IDs and `loginctl enable-linger` (https://docs.docker.com/engine/security/rootless/); Podman Quadlet turns `.container/.pod/.network/.volume/.image/.build/.kube` into systemd units, rootless, cgroup v2, `Notify=true|healthy`, `AutoUpdate=registry|local` (https://docs.podman.io/en/latest/markdown/podman-systemd.unit.5.html).
- Android: Go ships `android/arm64`; proot-distro gives a userland without root but no init, namespaces or cgroups — no containers (https://github.com/termux/proot-distro). modernc.org/sqlite v1.60.1 is CGo-free on 20 GOOS/GOARCH incl. windows/arm64 and linux/arm64 — **no android target listed** (https://pkg.go.dev/modernc.org/sqlite, 2026-09-29).

**Adopt / avoid:** One `dgo` binary that is at once CLI, `Type=notify` daemon with `WatchdogSec` + `StateDirectory` and a `systemd-analyze security --threshold` CI gate, launchd daemon installed via `launchctl bootstrap` (never `load`), and a Windows service via `x/sys/windows/svc` — no NSSM/WinSW. On Windows ship the engine as a `.wsl` distro (`systemd=true`, mirrored networking, `autoMemoryReclaim=gradual`) plus a Windows-side service that keeps the VM alive, since systemd units don't and `vmIdleTimeout` kills it; keep Docker 28.x until Traefik negotiates API versions. On macOS stay on Lima/VZ; track Apple `container`, don't adopt. Android: the Go core natively with a non-container subset, and verify its SQLite path.

## 8. Data layer

- SQLite core: WAL = many readers, one writer, same host (https://sqlite.org/wal.html); ≥3.51.3/3.53.0 fix a WAL-reset corruption bug (https://sqlite.org/changes.html, 2026-10-09).- Replication: Litestream v0.5 — LTX files, TXIDs, compaction levels, point-in-time restore from "a dozen or so files", one replica destination, CGO removed, NATS JetStream target; "the market has spoken! Users prefer Litestream" — LiteFS folded back (https://fly.io/blog/litestream-v050-is-here/); v0.5.17 adds `restore -f` follow mode and an experimental read-only VFS; "Windows is NOT an officially supported platform" (https://github.com/benbjohnson/litestream/releases, 2026-08-31).- Postgres: 18 — async I/O, `pg_upgrade` keeps planner statistics, `uuidv7()`, OAuth auth (https://www.postgresql.org/about/news/postgresql-18-released-3142/, 2025-09-25); the `postgres:18` image moved PGDATA to `/var/lib/postgresql/18/docker` so `pg_upgrade --link` works in place (https://hub.docker.com/_/postgres); pg_dump is "generally not the right choice" for regular production backups, pgBackRest/WAL-G give PITR (https://www.postgresql.org/docs/current/app-pgdump.html). Supabase self-host = 11 containers, 4 GB RAM minimum, a custom Postgres image that cannot share a stock cluster (https://supabase.com/docs/guides/self-hosting/docker).
- Backup: restic 0.19.1 — plain `check` is structure-only, `--read-data-subset=1/5` rotates full verification (https://restic.readthedocs.io/en/stable/045_working_with_repos.html).
- Event log: NATS JetStream 2.15 — streams, consumers, replay, KV/object store; R1 default = node loss is stream loss; leaf nodes connect outbound-only sites with their own JetStream domain; mirrors/sources catch up after gaps (https://docs.nats.io/nats-concepts/jetstream; https://docs.nats.io/running-a-nats-service/configuration/leafnodes).
- Local-first: Automerge 3.0, Rust/JS, no Go binding (https://automerge.org/blog/automerge-3/, 2025-07); cr-sqlite last released 2024-01-17 (https://github.com/vlcn-io/cr-sqlite/releases). Electric (shapes, HTTP long-poll; joining Neon/Databricks 2026-08-11), PowerSync (client SQLite, writes via your API, no Go SDK) and Zero all require one central Postgres with `wal_level=logical` — not peer-to-peer (https://electric.ax/; https://docs.powersync.com/self-hosting/installation).
- Secrets: age v1.3 adds ML-KEM-768 post-quantum recipients, v1.3.2 windows/arm64 (https://github.com/FiloSottile/age/releases, 2026-08-29); sops v3.13.3, CNCF sandbox (https://github.com/getsops/sops/releases, 2026-07-23); OpenBao v2.7.0, MPL-2.0 under OpenSSF (https://github.com/openbao/openbao/releases, 2026-09-23); go-keyring wraps macOS `security`, Windows Credential Manager, Secret Service (https://github.com/zalando/go-keyring); Compose secrets mount at `/run/secrets/<name>`, Linux only; env vars leak to every process and into logs (https://docs.docker.com/compose/how-tos/use-secrets/).

**Adopt / avoid:** SQLite (WAL, ≥3.51.3, one writer process, cgo-free driver) as the core's system of record, Litestream v0.5 per office to S3/SFTP/NATS verified by `restore -f`; one `postgres:18` per layer-3 app with in-place `pg_upgrade --link`, nightly `pg_dump -Fc` into restic with rotating `--read-data-subset` and a scripted restore test; a JetStream R1 stream per office with leaf-node mirrors over WireGuard as the audit/sync log; age + sops for the state file, OS keychain via go-keyring for the operator key. Avoid LiteFS, cr-sqlite, central-Postgres sync engines for peer offices, Vault/OpenBao on a single node, and secrets in environment variables.
