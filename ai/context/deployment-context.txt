# Deployment Context — deployment-hacohen (baseline inventory)

Single Debian host, one Docker Compose project rooted at `/root/deployment-hacohen`,
behind Traefik v3.3. Branch: `COPILOT`. Run ALL compose cmds from repo root.

## Domains
- Prod:  `<svc>.${DEPLOYMENT_DOMAIN}`        (DEPLOYMENT_DOMAIN = hacohen.bina-solutions.co.il)
- Dev:   `<svc>.dev.${DEPLOYMENT_DOMAIN}`     (DEV_DOMAIN = dev.<…>)
- Local: `<svc>.localhost`
- Containers: `<svc>-${DEPLOYMENT_NAME:-bina-deployment}` (a few use bare names: `apitools`, `feature-validation-api`, `*-validator`)
- SSL: Let's Encrypt HTTP-01, resolver `myresolver`, `traefik/acme.json`.

## Compose layout
```
compose.yml                      # traefik only + includes the two envs
production/compose.yml           # includes per-service prod stacks
production/compose.override.yml  # prod Traefik labels / routing / env
development/compose.yml          # includes per-service dev stacks
development/compose.override.yml # dev routing (*.dev.<domain>)
.env / .env.ex                   # config (DEPLOYMENT_DOMAIN, *_BASE_URL, secrets)
traefik/                         # traefik-dynamic.yaml, acme.json
```

## Traefik
- Entrypoints: web :80, websecure :443, postgres :5432, redis :6379 (TCP via ALPN).
- 600s read/write/idle timeouts. Dashboard gated by `TRAEFIK_API_DASHBOARD`.
- `exposedbydefault=false` — only labelled services are routed.

## Networks
- `traefik-network` (external) — all services + routing. Create once: `docker network create traefik-network`.
- Per-stack internal nets: authentik, glitchtip, supabase, librechat (legacy).

## Auth posture
- ForwardAuth (`middlewares=authentik`): homepage, redisinsight, machine, traefik dashboard, etc.
- Own auth (no ForwardAuth): n8n, authentik, portainer, glitchtip, supabase-studio (basic auth).

## What it does (business)
Hebrew financial-document automation: invoices / delivery notes / purchase orders /
balance sheets arrive via Gmail + Drive → apitools OCR + Gemini/Ollama extraction →
n8n "Incoming Documents" orchestrator (Google-Sheets state, Redis locks, Kafka) →
exposed to AI agents via n8n MCP servers + WhatsApp bot.

## Run commands (from repo root)
```
docker compose up -d                 # all
docker compose up -d <svc>           # one
docker compose up -d --build <svc>   # rebuild
docker compose ps / logs -f <svc>
./bbox n8n pull|push <app>|all      # workflows as code (apps/*/blueprint/n8n/*.workflow.ts)
./scripts/collect-logs.sh / pg-maintenance.sh / safe-clean.sh / storage-report
```
