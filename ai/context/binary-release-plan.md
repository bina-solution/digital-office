# השחרור הבינארי — התוכנית המלאה (הבעלים, 2026-10-14)

**מה הבעלים ביקש, בלשונו:** «תכתוב תוכנית מלאה להגיע למצב של שחרור בינארי להורדה לכל מערכת הפעלה זה
הולך להיות 3 חלקים. 1 קובץ מינימלי עד 5מב להורדה, וזה מוריד מעביר שלבי התקנה ראשוניים ואישור שימוש ושפה
(הכל ברירת מחדל פשוט ללחוץ הבא), את שכבה 0 של הלשכה שכוללת רק אפלקציות go לאבטחה, רשת,
התראות, קונסול, ניהול אפלקציות, הרחבה, וכו. ואז כשנפתח הקונסול לראשונה מציע לך שכבה 1 של אפליקציות
להורדה מהחנות (המלצה על בלופרינט של אפליקציות (ai, automation, project, indox, mail, drive etc)).
בעצם בשביל זה צריך גם להשלים את פרוייקט dgo net שמספק מגוון שירותים ביניהם repo ציבורי כמו npm רק dgo
לכל האפליקציות שאנחנו מציעים ואז יהיה אפשר להריץ `bbox install bina-ds` וכו. אתה מבין זה תוכנית ענקית…
תן לי תוכנית מלאה לביצוע ואת התקציב שאצתרך.»

**המצב היום, מדוד (2026-10-14, לשכת vps1):**
- `packaging/build-binaries.sh` — מסלול שחרור אחד שמייצר שלושה בינאריים לשישה יעדי OS/arch, עם
  `go vet`+`go test` לכל מודול ו-`SHA256SUMS`. נבנה היום בפועל: **dgo-install 5.2MB · dgo 2.5MB ·
  forward-auth 7.5MB** לווינדוס/amd64 + arm64, ול-`android/arm64` + `linux/arm64`.
- `dgo` (‏`packaging/dgo`) — ה-CLI האחד: המהדר **נייטיב חלקית** (`enabled-apps`, `validate`) והשאר
  מאציל ל-`platform/manager/reconcile.py` (עד שלב 2), וכל פקודות האפליקציות דרך `<app>/hooks/<verb>`.
- `forward-auth` (‏`platform-base/forward-auth`) — שירות הזהות ב-Go, 28 טסטים, **מוחזק לפני חיתוך**.
- `dgo-install` (‏`packaging/installer`) — Go, 11 טסטים, מאמת **מניפסט חתום** ונכשל-בטוח בלי חתימה.
- החוסר המרכזי: **אין מפתח חתימה ואין מארח מניפסט** (תשתית הבעלים), ואין עדיין שכבה 0 שכלולה בבינארי.

## חלק 1 — הטוען: קובץ אחד עד 5MB שמותקן בלחיצות „הבא”

**מה זה נותן:** הורדה אחת לכל מערכת הפעלה → הרצה → „הבא, הבא, הבא” (שפה, תנאי שימוש, אישור, מיקום) →
הבינארי מוריד את **שכבה 0** ומרים אותה → נפתח הקונסול.

**מה חסר, לפי הסדר:**

| # | מה | קבלה | הערכה |
|---|---|---|---|
| 1.1 | **חתימה** — מפתח ed25519 (`packaging/relsign` קיים; `--keygen`), ופרסום המפתח הציבורי בכל בינארי | `build-binaries.sh --sign-key` מייצר `manifest.json` חתום; הטוען מותקן ממנו; מניפסט מהונדס נדחה | הבעלים (`--keygen` + שמירה offline) |
| 1.2 | **מארח מניפסט** — `https://digital-office.co.il/dl/<os>/<arch>/manifest.json` (הנתיב כבר מוגדר) | `curl` מחזיר מניפסט חתום ל-6 יעדים | הבעלים (דומיין/אחסון) + חצי יום |
| 1.3 | **מסך ההרצה הראשון** — שפה, תנאי שימוש, אישור; ברירות מחדל ו„הבא” אחד לכל שלב | הרצה על מכונה נקייה: 4 מסכים, 0 קלט חוץ מ-Enter, נכתב `~/.bina/config.yaml` | 1 סיבוב (₪1.5) |
| 1.4 | **דיאטה ל-≤5MB** — היום windows/amd64 = 5,205KB (מעל). `-s -w` כברירת מחדל; יעד: הסרת embed מיותר + UPX אופציונלי | `ls -l` מראה ≤5,120KB לשלושת היעדים הדסקטופיים | 0.5 סיבוב (₪0.7) |
| 1.5 | **התקנה בלי `git clone`** (שלב 7 בתוכנית ה-core) — הטוען מוריד את שכבה 0 כארכיון חתום, לא ריפו | מכונה נקייה: מההורדה בלבד → קונסול עולה | 1 סיבוב (₪1.5) |

## חלק 2 — שכבה 0: הליבה ב-Go (אבטחה · רשת · התראות · קונסול · ניהול אפליקציות · הרחבה)

זו הלשכה **לפני** שיש בה אפליקציות עסקיות: כל מה שהמכונה צריכה כדי לארח אותן. לפי הסדר שבעבודות
(`ai/context/core-native-plan.md` §3), בתוספת שני השירותים שטרם נכתבו:

| רכיב | מצב | מה נדרש | הערכה |
|---|---|---|---|
| **מהדר** (שלב 2) | חלקי — 2 מילים בנייטיב, השאר מנותב לפייתון | להעביר verb-verb, כל אחד diff-test מול הפייתון על הקטלוג המקומט (`render` חייב בית-בית זהה) | 3–4 סיבובים (₪8–10) |
| **control plane** (שלב 3) | לא | `/api/apps`, מחזור חיים, `/api/office`, שומרי הקישור → `dgo serve` | 2–3 סיבובים (₪5–7) |
| **קונסול** (שלב 4) | לא — מכולת | שרת הקונסול + ה-embed של הסטטי → `console.localhost` מדgo | 2 סיבובים (₪4–5) |
| **כספת/חיבורים** (שלב 5) | לא — מכולת | הוואלט כקובץ שהבינארי מחזיק; ספקים מהמניפסטים; אשפי החיבור | 2–3 סיבובים (₪5–7) |
| **אבטחה/זהות** (שלב 6) | **כתוב** (`forward-auth`, 28 טסטים) | חלון החיתוך (F1–F3) + פרישת authentik | 1 סיבוב + חלון החלטה (₪2) |
| **רשת** — הקצה והמנהרות | קיים בפייתון/מכולות (`traefik`, `dgo-link`) | פרויקט **dgo-net**: מנהרת ה-WireGuard, דלת הקישור והקטלוג — כשירותי Go | 3–4 סיבובים (₪8–12) |
| **התראות** | מכולת פייתון | שירות התראות קטן ב-Go (upsert לפי `source_id`, level, link) | 1 סיבוב (₪1.5) |

**שער-על לשכבה 0:** מכונה נקייה עם הבינארי בלבד (בלי Docker מותקן?) — ההחלטה: האם שכבה 0 דורשת מנוע
מכולות. **ההצעה:** שכבה 0 רצה כבינאריים ישירים (Go) עם מנוע מכולות *אופציונלי* לאפליקציות שכבה 1 —
זה מה שהופך „לכל מערכת הפעלה” לאמת.
