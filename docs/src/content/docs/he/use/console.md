## למה

המרכז הוא המקום שממנו פותחים כל אפליקציה של הלשכה. כדאי להכיר אותו פעם אחת, ואחר כך כל אפליקציה נפתחת באותה דרך.

## לפני שמתחילים

נכנסתם ללשכה ([אחרי ההתקנה](/he/start/after-install)) ואתם רואים את המרכז.

## השלבים

1. **פותחים אפליקציה מהתפריט.** התפריט בצד מחולק לארבע קבוצות: «ראשי», «עסק», «תשתית» ו«הגדרות». לוחצים על אפליקציה, והיא נפתחת בתוך המרכז, בכתובת משלה. למשל, «קבצים» נפתחת ב-`#/m/drive`. אפליקציה שרצה ב[לשכה מקושרת](/he/concepts/link) מסומנת בסימן של אותה לשכה.
2. **מחפשים במקום לגלול.** `Ctrl K` (במק `Cmd K`) פותח חיפוש: כותבים חלק מהשם ופותחים את האפליקציה. `Esc` סוגר אותו.
3. **מגדילים למסך מלא.** הכפתור «מסך מלא» מסתיר את המעטפת ומשאיר רק את האפליקציה. הכפתור «יציאה ממסך מלא» מחזיר אותה.
4. **בטלפון יש סרגל למטה** עם שבעה מקומות:
   - «בית»;
   - ארבע אפליקציות;
   - «פתוחים», עם מספר האפליקציות שפתוחות עכשיו, כדי לחזור בלחיצה אחת למה שעשיתם;
   - «עוד».

   אפליקציה מקבלת מקום בסרגל כשהיא מבקשת אותו בהצהרה שלה, `app.json`.
5. **במסך רחב אפשר לעבור למצב שולחן עבודה.** מדליקים אותו במסך ההגדרות של המרכז: «מצב שולחן עבודה», במסכים ברוחב 1024 פיקסלים ומעלה.
   - כל אפליקציה נפתחת בחלון משלה, ובמרכז המסך יש אזור מיקוד.
   - חלון שנגרר לאחד הצדדים מתכווץ, אבל נשאר חי ופעיל.
   - ניעור של חלון שולח את כל השאר לצדדים.
   - הסרגל התחתון של שולחן העבודה מראה כמה אפליקציות שנכנסות בו. את השאר פותחים מ«עוד», שמראה את «כל האפליקציות» עם חיפוש.

   קיצורים במצב שולחן עבודה:

   | מקש | מה הוא עושה |
   |---|---|
   | `Ctrl K` | חיפוש ופתיחה של אפליקציה |
   | `Alt` ו-`` ` `` | מעבר בין חלונות |
   | `Shift` בזמן גרירה | הצמדה לחצי המסך, או הגדלה |
   | `?` | הצגה או הסתרה של כרטיס הקיצורים |

## איך בודקים שזה עבד

- `Ctrl K` פותח את החיפוש, ומשם אפליקציה נפתחת.
- בטלפון, «פתוחים» מראה את מה שפתחתם.
