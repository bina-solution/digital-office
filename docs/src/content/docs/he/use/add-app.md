## למה

הלשכה מריצה רק את האפליקציות שדולקות בה. מדליקים אפליקציה כשצריכים אותה, ומכבים כשלא. כיבוי שומר את הנתונים.

## לפני שמתחילים

- נכנסתם ללשכה כבעלים. המסך «אפליקציות» הוא למנהלים בלבד.
- המזהה של האפליקציה. כולם ב[דף האפליקציות](/he/apps).

## מהמסך

1. פתחו את «אפליקציות» במרכז.
2. מצאו את האפליקציה והדליקו אותה.

   המסך עושה את כל הדרך: כותב את ההחלטה, מכין את האפליקציה, מעלה אותה, מחכה שתהיה תקינה, ומחבר אותה לכניסה.

## מהמסוף

1. רשמו את ההחלטה:

   ```bash
   ./bbox apps enable <app>
   ```

   אפשר כמה אפליקציות בפקודה אחת.

2. העלו את הלשכה כדי שההחלטה תרוץ:

   ```bash
   ./bbox run
   ```

   בלי השלב הזה שום דבר לא עולה. `bbox apps enable` רק כותב את ההחלטה, ואומר את זה.

## לפני שמדליקים: יש מקום?

```bash
./bbox app-management room <app>
```

הפקודה אומרת אם יש במחשב מעבד וזיכרון בשביל האפליקציה.

## לכבות

```bash
./bbox apps disable <app>
./bbox run
```

הנתונים של האפליקציה נשמרים. כשמדליקים אותה שוב, הם שם.

אם אפליקציה דולקת אחרת צריכה אותה, היא ממשיכה לרוץ גם אחרי הכיבוי.

## אפליקציות שלא מכבים

אפליקציות הבסיס (`platform-base/`) לא נכבות מהמסך.

## איך בודקים שזה עבד

```bash
./bbox app-management apps
```

הפקודה מראה כל אפליקציה, מה הוחלט עליה ומה רץ בפועל. אפליקציה שהדלקתם מופיעה גם כאריח במרכז.
