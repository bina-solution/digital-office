## למה

«קבצים» (`drive`) הוא המקום של הלשכה לקבצים: מסמכים, תמונות, הקלטות וסרטונים. גם אפליקציות אחרות שומרות בו. עובדים לפי **נתיב**, למשל `/מסמכים/חוזים`.

## לפני שמתחילים

- «קבצים» דולקת. בהתקנה חדשה היא דולקת. אם לא: [להדליק אפליקציה](/he/use/add-app).

## מהמסך

1. פתחו את האריח «קבצים» במרכז.
2. פתחו תיקייה, וגררו לתוך המסך קובץ מהמחשב.

## מהמסוף

1. **להכניס קובץ:**

   ```bash
   ./bbox drive put ./doc.pdf /מסמכים/
   ```

   נתיב שנגמר ב-`/` שומר את שם הקובץ. תיקיות בדרך נוצרות לבד. אם השם תפוס, הקובץ החדש נקרא «name (2)». עם `--replace`, הקובץ הישן עובר לפח.

2. **לראות מה בתיקייה:**

   ```bash
   ./bbox drive ls /מסמכים
   ```

3. **למצוא לפי שם:**

   ```bash
   ./bbox drive find חשבונית
   ```

   מחזיר קבצים ותיקיות ששמם מכיל את הטקסט, עם הנתיב שלהם.

4. **להוציא קובץ למחשב:**

   ```bash
   ./bbox drive get "/מסמכים/doc.pdf" ./
   ```

5. **ליצור תיקייה:**

   ```bash
   ./bbox drive mkdir "/פגישות/2026-10-28"
   ```

כל הפקודות: `./bbox drive help`.

## כוננים

כל כונן הוא חיבור: פרופיל של האחסון של הלשכה, או חשבון Google. בלי `-p`, הפקודות עובדות על כונן ברירת המחדל.

```bash
./bbox drive profile list
```

הכונן שמסומן ב-`*` הוא ברירת המחדל. לעבוד על כונן אחר:

```bash
./bbox drive -p <drive> ls /
```

## תיקיות של המערכת

תיקייה שאפליקציה כותבת אליה מסומנת `system`. אי אפשר לשנות את שמה, להזיז אותה או למחוק אותה.

## איך בודקים שזה עבד

```bash
./bbox drive find doc
```

מה תראו: שורה עם הנתיב של הקובץ שהכנסתם.
