## למה

«מייל» (`mail`) מחזיק את כל תיבות הדואר של הלשכה במקום אחד: תיבות Gmail, והכתובות של שרת הדואר של הלשכה עצמה. כל תיבה היא **חיבור**.

## לפני שמתחילים

- «מייל» דולקת. בהתקנה חדשה היא דולקת. אם לא: [להדליק אפליקציה](/he/use/add-app).
- בשביל Gmail: סיסמת אפליקציה של חשבון Google שלכם.

## לחבר תיבה

1. פתחו את האריח «מייל» במרכז.
2. בחרו «חיבור חשבון».
3. חברו את Gmail בסיסמת אפליקציה.

![«מייל» עם חלון «חיבור חשבון» פתוח](TODO-shot: mail, «חיבור חשבון» פתוח, לשכת הדגמה, שולחן עבודה 1440x900, ערכה בהירה)

כל התיבות מופיעות בתפריט «חשבונות». התיבה שבחרתם בחלון אחד לא משנה דבר בחלון אחר.

## לקרוא ולמצוא מהמסוף

1. **התיבות, וברירת המחדל:**

   ```bash
   ./bbox mail profile list
   ```

   התיבה שמסומנת ב-`*` היא ברירת המחדל.

2. **המיילים החדשים בתיבה:**

   ```bash
   ./bbox mail -p <mailbox> inbox 5
   ```

   בלי מספר: עשרה.

3. **חיפוש:**

   ```bash
   ./bbox mail -p <mailbox> find "from:bank" 5
   ```

   החיפוש כתוב בשפת החיפוש של Gmail.

4. **מייל אחד:**

   ```bash
   ./bbox mail -p <mailbox> read <id>
   ```

`-p` בוחר תיבה לפי הכתובת, השם או המזהה שלה.

## לסמן ולתייג

```bash
./bbox mail -p <mailbox> mark <id> starred
./bbox mail -p <mailbox> tag <id> +<label>
```

סימון ותיוג משנים את התיבה עצמה, גם ב-Gmail. פקודה שכותבת לא רצה בלי `-p`, כדי שלא תכתוב לתיבה שלא בחרתם.

שליחה נעשית מהמסך בלבד.

## דואר מהאינטרנט לכתובות של הלשכה

בברירת המחדל, `MAIL_BIND=127.0.0.1` ב-`.env`. כך **שום מייל מהאינטרנט לא מגיע** לכתובות של הלשכה. לשכה עם כתובת ציבורית צריכה `MAIL_BIND=0.0.0.0`.

הדומיין של הכתובות הוא `MAIL_DOMAIN` ב-`.env`.

## איך בודקים שזה עבד

```bash
./bbox mail profile list
./bbox mail -p <mailbox> inbox 1
```

מה תראו: התיבה שחיברתם, והמייל האחרון בה.
