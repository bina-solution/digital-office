## למה

«בינה» (`bina-ds`) היא הסוכן של הלשכה. היא לא רק עונה: היא פועלת באפליקציות הדולקות. כל אפליקציה מלמדת אותה איך להפעיל אותה, בתדריך `AGENT.md` שלה.

## לפני שמתחילים

- «בינה» דולקת. בהתקנה חדשה היא דולקת.
- נכנסתם כבעלים. «בינה» היא למנהלים בלבד.
- מפתח לשירות של מודל שפה, שמור ב«חיבורים ומפתחות». «בינה» מכירה שלושה: DeepSeek,‏ OpenAI ו-Anthropic. זה שירות חיצוני, והמפתח שלכם.

## מהמסך

1. פתחו את האריח «עזריה» במרכז, בקבוצה «ראשי».
2. כתבו את הבקשה במילים שלכם. למשל: «מצאי לי את הקובץ doc.pdf בקבצים».

## מהמסוף

1. **משימה חדשה, ולעקוב עד הסוף:**

   ```bash
   ./bbox agent new -F "מצאי לי את הקובץ doc.pdf בקבצים"
   ```

   `-F` נשאר מחובר עד שהתור של הסוכן נגמר. Ctrl-C מתנתק, והמשימה ממשיכה.

2. **כל השיחות:**

   ```bash
   ./bbox agent list
   ```

3. **לעקוב אחרי שיחה:**

   ```bash
   ./bbox agent follow <id>
   ```

   `<id>` יכול להיות תחילת המזהה, אם היא ייחודית.

4. **להוסיף הודעה לשיחה:**

   ```bash
   ./bbox agent send <id> "גם את הקבצים מהחודש הקודם"
   ```

5. **לעצור:**

   ```bash
   ./bbox agent cancel <id>
   ```

עוד: `./bbox agent --help`.

## עם קובץ

```bash
./bbox agent new -f ./doc.pdf -F "מה כתוב בקובץ הזה?"
```

## איך בודקים שזה עבד

```bash
./bbox agent doctor
```

הפקודה עוברת על כל צעד מהמסוף עד הסוכן, עם זמנים. כשהכול תקין, `./bbox agent list` מראה את השיחה שפתחתם.

## כשמשהו לא עובד

הקודים ש-`bbox agent` יוצא איתם:

| קוד | פירוש |
|---|---|
| 0 | תקין |
| 1 | שגיאה |
| 2 | שימוש שגוי |
| 3 | הסוכן לא עונה, או שעבר הזמן |
| 4 | לא נמצא |
| 5 | הרשאה |
| 6 | המזהה לא ייחודי |
| 130 | נעצר ב-Ctrl-C |
