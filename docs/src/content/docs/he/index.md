DGO, «הלשכה הדיגיטלית», היא מערכת הפעלה ללשכה של עסק.
היא מריצה את האפליקציות של המשרד כקונטיינרים, על מחשב שלכם.
כל אפליקציה מוצהרת בקובץ אחד, והמערכת בונה ממנו את מה שרץ.

![המרכז של לשכת הדגמה: מסך הבית עם אריח לכל אפליקציה](TODO-shot: המרכז (console), מסך הבית עם האריחים; שולחן עבודה 1440x900, ערכה בהירה)

## מה יש בלשכה

- **המרכז**: המסך שמכיל את כל האפליקציות של הלשכה, כל אחת כאריח.
- **כניסה אחת** לכל האפליקציות.
- **אוטומציות** עם `n8n`, וקליטה של מסמכים פיננסיים בעברית עם זיהוי טקסט.
- **קבצים, דואר, צ'אט, ניהול משימות** ועוד אפליקציות, שמדליקים ומכבים לפי הצורך.
- **סוכן של הלשכה**, «בינה», שפועל באפליקציות שהדלקתם.
- **כמה מחשבים, לשכה אחת**: לשכות מקושרות פותחות זו את האפליקציות של זו.

## איך מתקינים

ההתקנה: `git clone https://github.com/bina-solution/digital-office`, ואחר כך פקודה אחת או שתיים לפי המחשב:
- על לינוקס: `./bbox install debian`, ואז `./bbox run`.
- על macOS: `./bbox run`.
- על Windows: `bbox.cmd install windows`, ואז `bbox.cmd run`.
