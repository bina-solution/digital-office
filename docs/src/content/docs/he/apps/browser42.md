## מה הוא

«דפדפן הלשכה» (`browser42`) הוא Chromium אחד ומשותף של הלשכה: פרופיל אחד ועוגיות אחת, מחובר לאתרים שהבעלים נכנס אליהם פעם אחת. משתמשים בו לאתר שאין לו API, לקרוא עמוד כמו שאדם רואה אותו, ולהעביר לאדם מסך: קוד QR או כניסה. הבעלים רואה את אותו דפדפן חי באריח, ולכן כל לשונית שנפתחת בו נמצאת מול העיניים שלו.

הוא למנהלים בלבד, כבוי בהתקנה חדשה, ונמצא באריח «דפדפן הלשכה» בקבוצה «עסק». [רשתות חברתיות](/he/apps/social-list) משתמשת בו ברשת שאין לה API.

**הוא כבד:** שש מכולות, עם מגבלות של כ-3.7 GB ביחד. במחשב עם זיכרון קטן כדאי לחשוב לפני שמדליקים.

מדליקים אותו במסך האפליקציות, שעושה את כל הדרך, או בשורת הפקודה. שם `apps enable` רק כותב את ההחלטה, ו-`./bbox run` מעלה אותו:

```bash
./bbox apps enable browser42
./bbox run
```

## הוא פועל בשם הבעלים

- **לחיצה באתר מחובר היא לחיצה של הבעלים.** קוראים בחופשיות. מה ששולח, קונה, מוחק או מגיש באתר דורש את האישור שלו, במילים שלו.
- **אף אחד לא מקליד סיסמה.** לאתר נכנס אדם, במסך החי, או שהדפדפן ממלא את הסיסמה בעצמו ממאגר הסיסמאות שלו. הכניסה האוטומטית היחידה היא ל-Facebook, והיא לוקחת את פרטי הכניסה מהכספת בלי שהם יופיעו בשום מקום.
- **מסירה לאדם:** כשאפליקציה צריכה אדם, למשל לסריקת QR, הלשכה מביאה את הדפדפן למי שמסתכל, וממתינה עד שהעמוד אומר שהוא סיים.

## משורת הפקודה

| פקודה | מה היא עושה |
|---|---|
| `./bbox b42 page <url>` | פותחת עמוד, מחזירה את הטקסט שלו, וסוגרת |
| `./bbox b42 shot <url>` | פותחת עמוד, מצלמת אותו, וסוגרת |
| `./bbox b42 tab list` | הלשוניות הפתוחות |
| `./bbox b42 logins sessions` | לאילו אתרים הדפדפן מחובר |
| `./bbox b42 sleep status` | הדפדפן נרדם כשאין עבודה. `wake` מעיר אותו |

## מה רק הבעלים עושה

- **מחיקת כל הכניסות** (`state reset --yes`), שמירה או החלפה של הפרופיל (`state dump|load`, שעוצרות את הדפדפן).
- **כתיבה למאגר הסיסמאות של הדפדפן או לכספת.** כשהדפדפן מחזיק את המאגר, זה גם מפעיל אותו מחדש.

## מה עוד לא עובד היום

- **הדלת של המשימות עונה גם בלי אסימון.** יש בה בדיקה של אסימון, אבל ברירת המחדל היא «להזהיר» (`BROWSER42_TASK_AUTH=warn`): מי שפונה בלי אסימון מקבל שירות, ונרשם ביומן. אליה מגיעות המכולות של הלשכה, והלשכות שהאפליקציה הזו ניתנה להן. `refuse` עונה 401.
- **כבד בזיכרון.** במחשב עם זיכרון קטן הדפדפן יכול להחזיק מאות תהליכים.
- **הדפדפן חולק רשת עם כל האפליקציות.** מה שמונע מהן להגיע ישר לממשקים הפנימיים שלו (השליטה בדפדפן, התצוגה החיה) הוא רק סקריפט ההפעלה, שקושר אותם לכתובת המקומית. התקלה פתוחה.
