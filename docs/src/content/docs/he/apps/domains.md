## מה היא

«דומיינים» (`domains`) מחזיקה את הדומיינים של העסק: התוקף מול הרישום, ספקי ה-DNS והרשמים מאחורי ממשק אחד, והרשומות. היא למנהלים בלבד, כבויה בהתקנה חדשה, ונמצאת באריח «דומיינים» בקבוצה «עסק».

מדליקים אותה במסך האפליקציות, שעושה את כל הדרך, או בשורת הפקודה. שם `apps enable` רק כותב את ההחלטה, ו-`./bbox run` מעלה אותה:

```bash
./bbox apps enable domains
./bbox run
```

## חשבון, הדומיינים שבו, ודומיין אחד

- **חשבון** הוא [חיבור](/he/concepts/connection): חשבון API (למשל GoDaddy, Cloudflare, Plesk, Porkbun, DigitalOcean, Gandi או Hetzner), או **חשבון דפדפן**, אצל רשם שאין לו API. רשם כזה הוא אפליקציה משלו: InterNIC היא `domain-internic`. לחשבון דפדפן צריך להדליק גם אותה וגם את [דפדפן הלשכה](/he/apps/browser42).
- **מעקב רישום** פועל תמיד, בלי סיסמה: הוא שואל את המרשם הציבורי (WHOIS) על כל דומיין שהלשכה מכירה.
- **חשבון דפדפן** מתחבר כשהבעלים נכנס פעם אחת לפאנל, ב[דפדפן הלשכה](/he/apps/browser42). החיבור נשמר רק אחרי שהלשכה קראה מהחשבון את רשימת הדומיינים שלו, כהוכחה.
- **דומיין אחד** מראה סקירה, רשומות, בריאות, פעולות, ויומן של כל שינוי עם מצב לפני ואחרי, ואפשרות לבטל.

## משורת הפקודה

| פקודה | מה היא עושה |
|---|---|
| `./bbox domains accounts` | החשבונות, בלי לפנות אליהם |
| `./bbox domains ls` | הדומיינים של חשבון, או כל הדומיינים שהלשכה מכירה |
| `./bbox domains show <domain>` | דומיין אחד: רשם, תוקף, שרתי שמות ומצב |
| `./bbox domains records <domain>` | רשומות ה-DNS, כמו שהספק מדווח עליהן |
| `./bbox domains whois <domain>` | שאילתה חיה אחת למרשם הציבורי. לא בלולאה |

בחשבון דפדפן, `ls`, `show` ו-`records` קוראים את הפאנל בדפדפן של הלשכה.

## מה דורש אדם

- **כתיבה בפאנל רצה פעם ראשונה כשאדם צופה.** עד אז היא מסורבת.
- **פעולה שעולה כסף או שאי אפשר לבטל** צריכה אישור מדויק: שם הדומיין והפעולה, לא «כן».
- **קריאה שנכשלה לא נשמרת כאמת.** המסך שומר את הרשימה האחרונה שהצליחה ומסמן אותה כישנה. אזור DNS ריק שנראה רגיל הוא התשובה השגויה היחידה שאסור להראות.
- **רשומה שהפאנל לא מציג** אבל העולם כן עונה עליה מסומנת «קיים בעולם; הפאנל הזה לא מציג את הסוג הזה», ולא כרשומה חסרה.

## מה עוד לא עובד היום

- **תקלה או השהיה של דפדפן הלשכה** מוצגת כ«הדפדפן לא זמין», ואף פעם לא ככניסה שנכשלה. הדפדפן עולה שוב לבד.
- **ב-InterNIC** אפשר היום רק ליצור רשומה. עדכון ומחיקה עוד לא כתובים.
