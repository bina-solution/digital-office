## מה היא

«מכונה» (`machine`) מראה את המספרים של המחשב שהלשכה רצה עליו: מעבד, זיכרון ודיסק, כל קונטיינר וכמה הוא צורך, מה תופס את הדיסק, מה אפשר לנקות, ומדיניות החשמל. היא חלק מהבסיס של כל לשכה (שכבה 2), ולמנהלים בלבד.

## איפה רואים אותה

אין לה אריח משלה. המסך שלה נמצא בתוך «מחשבים». גם הכרטיס «חשמל ושינה» במסך ההגדרות של המרכז קורא ממנה וכותב דרכה.

## משורת הפקודה

ארבע הפקודות רק קוראות, ולא משנות כלום:

| פקודה | מה היא מראה |
|---|---|
| `./bbox machine overview` | מעבד, זיכרון, דיסק, וכמה כל קונטיינר צורך |
| `./bbox machine storage` | מה תופס את הדיסק: אימג׳ים, נפחים, מטמון בנייה |
| `./bbox machine cleanup-options` | מה ניקוי יכול לפנות, ואילו פעולות מותרות בלשכה הזו |
| `./bbox machine power` | מדיניות החשמל, והנתונים של המחשב עצמו |

כדאי להריץ `./bbox machine overview` לפני בנייה כבדה, כדי לראות שיש מקום.

## ניקוי

ניקוי פועל על כל המנוע: כל קונטיינר עצור, כל אימג׳ שלא בשימוש, או מטמון הבנייה.
כברירת מחדל אף פעולת ניקוי לא מותרת. הלשכה מסרבת לכל ניקוי עד שמנהל מתיר אותו במפורש. אימג׳ שנמחק צריך להיבנות מחדש, וקונטיינר עצור יכול להיות עבודה של מישהו שמחכה.

## חשמל ושינה

מדיניות החשמל קובעת אם המחשב רשאי לישון. ברירת המחדל היא להמשיך לעבוד.
ב-Mac, מחשב שישן מקפיא את המנוע ואת כל מה שרץ בו, כולל הסוכנים.
«מכונה» לא מכבה את המחשב ולא מפעילה אותו מחדש.

## איך בודקים שהיא עובדת

`./bbox machine overview` מחזיר את המספרים של המחשב ואת רשימת הקונטיינרים.
