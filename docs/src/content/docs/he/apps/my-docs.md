## מה היא

«מסמכים שלי» (`my-docs`) היא המסך של המסמכים העסקיים: הצעות מחיר, חשבוניות, קבלות ומסמכי זיכוי, עם הלקוחות והפריטים שלהם. היא כבויה בהתקנה חדשה, ונמצאת באריח «מסמכים שלי» בקבוצה «עסק».

מדליקים אותה במסך האפליקציות, שעושה את כל הדרך, או בשורת הפקודה. שם `apps enable` רק כותב את ההחלטה, ו-`./bbox run` מעלה את האפליקציה:

```bash
./bbox apps enable my-docs
./bbox run
```

המסמכים עצמם נשמרים בפנקס של [כלי מסמכים](/he/apps/apitools): הוא ממספר אותם, מייצר את הקובץ ושומר יומן של כל שינוי. «מסמכים שלי» היא המסך שמעליו.

## מה סופי

- **הנפקה סופית.** מסמך שהונפק מקבל את המספר הבא בסדרה, ומספר לא חוזר לעולם. כדי לבטל מסמך שהונפק מבטלים אותו, וזה מנפיק לידו חשבונית זיכוי, לכל סוג של מסמך.
- **ההורדה הראשונה היא «מקור».** הפנקס רושם את ההורדה הראשונה כ«מקור» וכל אחת אחריה כ«העתק», גם של הבעלים. הסימון מודפס על הקובץ רק בהורדה כתמונה (PNG). קובץ PDF יוצא אותו דבר בכל הורדה.
- **«נשלח» לא שולח מייל.** הוא רק מסמן שהמסמך נשלח ורושם את הכתובת ביומן. שליחת הקובץ ללקוח היא פעולה נפרדת.

טיוטה אפשר להכין ולשנות בחופשיות.

## משורת הפקודה

הפקודות כאן קוראות בלבד:

| פקודה | מה היא עושה |
|---|---|
| `./bbox my-docs documents` | המסמכים |
| `./bbox my-docs show <id>` | מסמך אחד |
| `./bbox my-docs events <id>` | היומן של מסמך |
| `./bbox my-docs customers` | הלקוחות |
| `./bbox my-docs items` | הפריטים |
| `./bbox my-docs integrity` | בודקת שהמספור רציף ושהיומן לא שונה. בלשכה בלי תעודת חתימה, הבדיקה הראשונה יוצרת את תעודת הפיתוח. היא לא משנה אף מסמך |

## מה עוד לא עובד היום

- **מסמך שמונפק כאן עוד לא חוקי כברירת מחדל.** מספר ההקצאה של חשבוניות ישראל מגיע ממימוש לבדיקות, והחתימה הדיגיטלית היא חתימה עצמית. ראו [כלי מסמכים](/he/apps/apitools).
- **אין לפנקס כניסה משלו.** הכניסה של הלשכה בנתב הקצה היא השער היחיד, ולכן לא חושפים את היציאה של `apitools`.
