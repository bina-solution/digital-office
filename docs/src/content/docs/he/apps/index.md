## איך לקרוא את הטבלה

- **מזהה** הוא השם של האפליקציה בפקודות: `./bbox apps enable <id>`.
- **שכבה**: 1 ו-2 הן הבסיס של כל לשכה (`platform-base/`). 3 הן אפליקציות שמוסיפים (`apps/`).
- **דולקת בהתקנה חדשה**: מה שקובץ ברירת המחדל `platform.state.default.yaml` אומר. אפליקציה שלא מופיעה בו כבויה, חוץ מ«מכולות», שדולקת כל עוד מצב הלשכה (`platform.state.yaml`) לא אומר אחרת.
- **למנהלים בלבד**: אדם שהזמנתם ללשכה לא פותח את האפליקציה הזו.

## לראות את הרשימה של הלשכה שלכם

```bash
./bbox apps list
```

המסך «אפליקציות» מראה את אותה רשימה, עם המצב של כל אפליקציה.
