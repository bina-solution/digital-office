## מה היא

«אבטחה» (`security`) מראה מי ניגש ללשכה ולאן הלשכה פונה, ויש בה מנגנון שחוסם כתובות שתוקפות. היא למנהלים בלבד, ונמצאת באריח «אבטחה» בקבוצה «ראשי».

בקובץ ברירת המחדל היא כבויה. `./bbox onboarding` מדליק אותה בעצמו במחשב שיש לו כתובת ציבורית. במקום אחר מדליקים אותה בשורת הפקודה: `apps enable` רק כותב את ההחלטה, ו-`./bbox run` מעלה אותה:

```bash
./bbox apps enable security
./bbox run
```

היא רצה בשני חלקים: המסך והשירות שמאחוריו, שנמצאים מאחורי הכניסה, וחיישן שקורא את התעבורה של המחשב. לחיישן אין כתובת שאפשר לפנות אליה.

## מה היא מראה

- **מי ניגש:** שורה לכל כתובת, עם המקום, הרשת, האפליקציות שנפתחו והמשתמשים.
- **לאן הלשכה פונה:** לפי יעד, עם השמות, מי פנה, והאם אפליקציה הצהירה על היעד הזה.
- **כניסות SSH:** אילו מפתחות נכנסו, וכל ניסיון שנכשל.
- **מה לשכות מקושרות פתחו כאן.**
- **חסימות:** המצב, הכללים והכתובות שחסומות עכשיו.

## משורת הפקודה

| פקודה | מה היא עושה |
|---|---|
| `./bbox security summary` | המספרים של 24 השעות האחרונות: בקשות, כתובות, חסימות ופניות החוצה |
| `./bbox security inbound` | מי ניגש, לפי כתובת |
| `./bbox security outbound` | לאן הלשכה פנתה, ומי פנה |
| `./bbox security ip <address>` | כתובת אחת: הפניות שלה, הכניסות והחסימות |
| `./bbox security bans` | המצב, הכללים והחסימות הפעילות |
| `./bbox security herd` | הסיכום של כל לשכה מקושרת |
| `./bbox security verify` | האפליקציה עונה, החיישן כותב, ויומן נתב הקצה נקרא |

ל-`summary`, `inbound` ו-`outbound` אפשר לתת מספר שעות.

## איך היא מחליטה לחסום

| מה נחשב התקפה | הסף |
|---|---|
| סריקה: בקשות שנכשלות, או פניות לנתיבים שמחפשים פרצות, במה שפתוח בלי כניסה (אתר ציבורי, הדלת של קישור, שם שאף אחד לא מנתב) | 12 כישלונות, או 3 נתיבים כאלה, ב-10 דקות |
| ניסיונות כניסה שנכשלו | 5 ב-15 דקות |
| ניסיונות SSH שנכשלו | 5 ב-10 דקות |

בקשה ל-`/` או לסמל האתר ששבה 404, בשם שאף אחד לא מנתב, לא נחשבת סריקה: כך כל דפדפן שואל על שם שלא ראה.

חסימה ראשונה היא לשעה, וכל חזרה מכפילה אותה פי 4, עד שבעה ימים לכל היותר.

**מי לא נחסם לעולם:** כתובות פרטיות, הכתובות של הלשכה עצמה, לשכות מקושרות, כתובת שנכנסה בהצלחה ב-30 הימים האחרונים, ומה שברשימת ההיתרים.

## צפייה ואכיפה

לשכה חדשה מתחילה **בצפייה**. החלטה לחסום נרשמת כ«היה נחסם», ושום דבר לא נחסם באמת. הבעלים עובר לאכיפה במסך, בלשונית החסימות («מעבר לאכיפה»). סוכן לא מחליף את המצב.

גם הפניות החוצה רק מסומנות. פנייה ליעד שאף אפליקציה לא הצהירה עליו מסומנת, ולא נחסמת.

מלשכה מקושרת אי אפשר לשנות כלום כאן: לא חסימות, לא כללים ולא את המצב, אלא אם הלשכה הזו התירה את זה במפורש.

## מה עוד לא עובד היום

- **מסך האפליקציות לא מדליק אותה.** אפליקציה מהבסיס נדלקת היום רק בפקודה או בהתקנה הראשונה.
- **במחשב נייד היא לא רואה את הכתובת האמיתית.** שם הלשכה רצה בתוך מכונה וירטואלית, ונתב הקצה רואה את הכתובת של המחשב עצמו, לא של מי שפנה. בשרת היא רואה את הכתובות האמיתיות, חוץ ממה שמגיע ב-IPv6.
- **מבקר ב-IPv6 נראה כמו הלשכה עצמה.** בשרת עם כתובת IPv6 ציבורית, מבקר ב-IPv6 מגיע מכתובת פנימית, ולכן הוא לא נחסם לעולם. עד שזה מתוקן, סוגרים את IPv6 ליציאות 80 ו-443 בחומת האש של השרת.
- **שום דבר לא נחסם עד שהבעלים עובר לאכיפה,** ופנייה החוצה ליעד לא מוצהר רק מסומנת.

## מה היא מורידה מבחוץ

בהפעלה הראשונה היא מורידה מאגר מיקומים חינמי (DB-IP lite, ברישיון CC BY 4.0), כדי לדעת מאיפה מגיעה כל כתובת:

| `SECURITY_GEO` | מה נשמר | גודל בדיסק |
|---|---|---|
| `city` (ברירת המחדל) | מדינה, עיר ורשת | כ-145 MB |
| `country` | מדינה ורשת | כ-18 MB |
| `off` | כלום. שום דבר לא יורד | — |
