## מה היא

«בינה» (`bina-ds`) היא אפליקציית הסוכנים של הלשכה: רתמה בעברית שבה גרים סוכני הלשכה. היא דולקת בכל לשכה חדשה. במרכז היא באריח «בינה ודעת» בקבוצה «ראשי», למנהלים בלבד.

- **«עזריה»** הוא סוכן ברירת המחדל, והוא פועל.
- **«רפאל»** הוא השומר, והוא רק מציע.

אנשים מדברים איתם באריח. כל קורא אחר (סקריפט, סוכן אחר, לשכה מקושרת) מדבר עם הסוכן דרך ממשק אחד, `agent.v1`, ומהמסוף זה `./bbox agent`. איך הסוכן לומד את האפליקציות: [סוכן](/he/concepts/agent).

## מה עולה כסף ומה חינם

- **שיחה עולה כסף, ופועלת.** הודעה חדשה, משימה או מטרה מפעילות את מודל השפה, והסוכן עובד עם גישה מלאה ללשכה. הודעה לסוכן היא הוראה למפעיל עם הרשאות מלאות, ולכן נותנים לו רק את מה שבאמת ביקשתם.
- **לקרוא שיחות זה חינם.** ביטול עוצר את התור שרץ עכשיו.
- המודל עצמו הוא [חיבור](/he/concepts/connection): מפתח שנשמר ב«חיבורים ומפתחות».

## מה רק הבעלים מחליט

- החלפת המודל משנה גם את מודל ברירת המחדל של הלשכה.
- החלפת ה-preset משנה איך שיחה מתנהגת.

## עדכון בלי לעצור עבודה

לא בונים את «בינה» מחדש מתוך שיחה שרצה בה. כשפקודה הייתה בונה אותה מחדש מבפנים, הלשכה מעבירה את העבודה לעוזר שרץ מחוץ לה. העוזר מחכה לשקט, כופה את העדכון אחרי שלוש שעות, וחוזר לגרסה הקודמת אם החדשה לא תקינה.

## משורת הפקודה

| פקודה | מה היא עושה |
|---|---|
| `./bbox agent list` | השיחות: רצות או ממתינות, כותרת ומטרה |
| `./bbox agent show <id>` | שיחה אחת. קריאה, חינם |
| `./bbox agent wait <id>` | מחכה שהשיחה תסיים |
| `./bbox agent cancel <id>` | עוצר את התור שרץ |
| `./bbox agent new <text>` | שיחה חדשה. עולה כסף |

בלשכה שבה «בינה» כבויה, `./bbox agent --office <office>` מגיע לסוכן של לשכה מקושרת.

## איך בודקים שהיא עובדת

- האריח «בינה ודעת» נפתח ומראה את השיחות.
- `./bbox agent list` מחזיר את רשימת השיחות.
