## מה היא

«מכולות» (`containers`) היא האפליקציה האחת שאחראית על הרצת מכולות. כל אפליקציה שרצה במכולה צריכה אותה, והלשכה מוסיפה אותה בשבילה, כמו שאפליקציה עם בסיס נתונים מוסיפה את בסיס הנתונים. היא למנהלים בלבד, ואין לה אריח.

היא לא מריצה מכולה משלה. המנוע הוא המנוע של המחשב שהלשכה רצה עליו.

**היא דולקת תמיד,** כל עוד מצב הלשכה (`platform.state.yaml`) לא אומר אחרת. בכל מערכת חוץ מ-Android, הבסיס של הלשכה עצמו רץ במכולות, אז המנוע קיים לפני כל דבר אחר.

## המנוע בכל מערכת הפעלה

| מערכת | המנוע היום |
|---|---|
| Linux | Docker 28.5.2, ישירות על המחשב |
| macOS | Docker בתוך מכונה וירטואלית של Lima |
| Windows | Docker בתוך הפצת WSL |
| Android | Docker במכונה וירטואלית של הלשכה |
| iOS | אין. האפליקציה מגיעה ללשכה שרצה במחשב אחר |

בסיסי הנתונים נשמרים בכרכים על הדיסק של המנוע.

## מה עוד לא עובד היום

- **המנוע נעול על Docker 28.5.2, בכל מערכת.** מה שקובע הוא אם המנוע עונה ללקוח בגרסת API 1.24, כמו שנתב הקצה מדבר. ב-Docker 29 זה עובד רק עם `DOCKER_MIN_API_VERSION=1.24`. בלי זה הנתב לא מנתב כלום, בלי הודעה. ראו [דרישות](/he/start/requirements).
- **חלק מהקבצים של אפליקציות עדיין בתיקיית הלשכה.** ב-macOS התיקייה הזו משותפת עם המחשב, ולכן הקבצים האלה לא נמצאים בדיסק של המכונה הווירטואלית. להעביר אותם לשם זו עבודה מתוכננת. רק ב-Android הכול כבר בתוך המכונה.
- **ב-Android** הבסיס של הלשכה רץ בלי מכולות, אבל חלק מהאפליקציות של הליבה עדיין מפעילות את המנוע. השלב הבא: שהבסיס יעלה בלי המנוע, ו«מכולות» תותקן רק כשמבקשים אותה.
