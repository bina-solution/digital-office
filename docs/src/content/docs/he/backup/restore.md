## למה

ארכיון של `bbox export` מחזיר את הלשכה: מסדי הנתונים, האוטומציות, המסמכים, המשתמשים ו-`.env`.

## לפני שמתחילים

- ארכיון מ-`./bbox export`. ראו [גיבוי](/he/backup).
- לשכה מותקנת בתיקייה חדשה. ראו [התחלה — בחרו מחשב](/he/start).

## השלבים

1. **שימו את הארכיון בתיקייה החדשה,** בתוך `exports/`.

2. **שחזרו:**

   ```bash
   ./bbox import
   ```

   בלי תיקייה, הפקודה לוקחת את הארכיון האחרון ב-`exports/`. ארכיון אחר:

   ```bash
   ./bbox import exports/<archive>
   ```

3. **קראו מה הפקודה אומרת.** היא כותבת מאיזו לשכה הארכיון בא, ולאיזו הוא משוחזר. לפני שהיא כותבת, היא בודקת כל קובץ בארכיון לפי `sha256`. אחרי השחזור, היא משווה את מספר השורות בכל טבלה למקור.

## אפליקציה אחת בלבד

```bash
./bbox import --app <app>
```

מחזיר רק את הנתונים של האפליקציה הזו, גם מארכיון של כל הלשכה. השאר לא נוגעים.

## מה הפקודה מסרבת לעשות

- **לכתוב על הלשכה שהארכיון בא ממנה.** זו הגנה. אם זה באמת מה שאתם רוצים, `--force`.
- **לשחזר ארכיון בגרסת פורמט אחרת.**

## איך בודקים שזה עבד

```bash
./bbox status
./bbox verify
```

והיכנסו למרכז: האפליקציות, הקבצים והמשתמשים שהיו בלשכה המקורית.
