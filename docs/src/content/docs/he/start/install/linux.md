## למה

על לינוקס הלשכה רצה ישירות על Docker של המחשב, בלי מכונה וירטואלית.

## לפני שמתחילים

- מחשב או שרת עם Debian או Ubuntu, והרשאת `sudo`.
- [הדרישות](/he/start/requirements): אם Docker כבר מותקן, הוא חייב להיות מגרסה 28.
- המאגר הציבורי הוא `bina-solution/digital-office`.

## השלבים

1. שכפלו את המאגר ועברו לתיקייה שלו:

   ```bash
   git clone https://github.com/bina-solution/digital-office
   cd digital-office
   ```

2. התקינו את התלויות: `git`, Docker ומה שהלשכה צריכה.

   ```bash
   ./bbox install debian
   ```

   הסקריפט `./debian-install.sh` עושה אותו דבר. הוא מתקין Docker 28.5.2 ונועל אותו, ויוצר `.env` מהתבנית `.env.ex` (קובץ `.env` קיים נשאר כמו שהוא).
   אם הוא הוסיף אתכם לקבוצה `docker`, התנתקו והתחברו שוב לפני הצעד הבא.

3. ערכו את קובץ ההגדרות `.env`. התבנית אומרת שיש בו שורה אחת לערוך: `BUSINESS_NAME`, שם העסק. כל השאר נגזר ממנה: שם הלשכה, הדומיין וכל הכתובות.

   ```bash
   BUSINESS_NAME=MyOffice
   ```

   את `DEPLOYMENT_NAME`, `DEPLOYMENT_DOMAIN` וערכי `*_BASE_URL` לא עורכים ביד: הם נגזרים.
   דומיין משלכם: השורה `COMPANY_BASE_DOMAIN`. התבנית מזכירה שדומיין צריך גם רשומות DNS.

   **אין לכם דומיין (מחשב נייד, ניסיון)? לשכה מקומית.** בצעד 2 מריצים `DGO_LOCAL=1 ./debian-install.sh`, שלא מעתיק `.env`, ומדלגים על הצעד הזה. אחר כך `./bbox run` יוצר בעצמו לשכה מקומית: כל אפליקציה ב-`<app>.localhost`, והמרכז ב-`http://console.localhost`. אם כבר יש במחשב קונטיינרים או נפחים של הלשכה מהתיקייה הזו, הוא מסרב ואומר למה. אם `BUSINESS_NAME` ריק בלשכה עם דומיין, `./bbox run` מסרב ואומר בשורה אחת מה לכתוב.

   את הסודות (סיסמאות, מפתחות) אין צורך לכתוב: ההרצה הראשונה של `./bbox run` ממלאת אותם, כל עוד אין במחשב נתונים של הלשכה.

4. העלו את הלשכה:

   ```bash
   ./bbox run
   ```

   הפקודה מהדרת את ההצהרות ומעלה את כל השירותים. בהרצה הראשונה היא בונה את האימג'ים, וזה לוקח 10 עד 15 דקות במחשב קטן.
   בלשכה חדשה היא מדפיסה שורה שמתחילה ב-`[forward-auth] first run: open`, ובה קישור חד-פעמי לפתיחת המנהל הראשון. ראו [אחרי ההתקנה](/he/start/after-install).

**אל תריצו `docker compose` ישירות.** הקובץ `compose.yml` שבשורש מצהיר רק על הרשת. פקודת `docker compose up -d` מוצאת אפס שירותים ומסתיימת בהצלחה, בלי לעשות כלום. השתמשו ב-`./bbox run`.

## איך בודקים שזה עבד

```bash
./bbox status
```

הפקודה מראה את הקונטיינרים, את `n8n` ואת ההרשאות. בדיקה מחמירה יותר, שיוצאת בשגיאה אם משהו שבור:

```bash
./bbox verify
```

## אם משהו לא עובד

- **כל הכתובות מחזירות 404, והכול "תקין":** בדקו את גרסת Docker (`docker version`). הגרסה שנבדקה היא 28; לפי התיעוד של המאגר, על 29 זה מה שעלול לקרות.
- **`postgres` לא עולה ב-Ubuntu 26.04:** `./bbox apparmor status`, ראו [דרישות](/he/start/requirements).
