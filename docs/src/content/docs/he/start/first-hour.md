## מה יהיה לכם בסוף

לשכה שבה אפליקציית «קבצים» דולקת, ובה קובץ שלכם.
הסוכן של הלשכה, «בינה», מצא את הקובץ כשביקשתם.

## לפני שמתחילים

- לשכה מותקנת ופועלת: [התחלה — בחרו מחשב](/he/start), ואחר כך [אחרי ההתקנה](/he/start/after-install).
- המנהל הראשון כבר נוצר, דרך הקישור החד-פעמי ש-`./bbox run` הדפיס ([אחרי ההתקנה](/he/start/after-install), שלב 2). צריך את השם והסיסמה שבחרתם שם.
- קובץ קטן להעלאה, למשל PDF של חשבונית.
- בשביל «בינה»: מפתח לשירות של מודל שפה. הסוכן מכיר שלושה חיבורים: DeepSeek,‏ OpenAI ו-Anthropic. המפתח הוא שלכם, והוא שירות חיצוני.

## השלבים

1. **היכנסו.** פתחו את כתובת המרכז: הערך של `CONSOLE_BASE_URL` ב-`.env`, ועל macOS `http://console.localhost:8080`. הקלידו את השם והסיסמה.

   מה תראו: המרכז, «המרכז» בכותרת, ואריח לכל אפליקציה דולקת.

   ![המרכז מיד אחרי הכניסה הראשונה](TODO-shot: first-hour-1-console — המרכז של לשכת הדגמה מיד אחרי הכניסה הראשונה; שולחן עבודה 1440x900, ערכה בהירה וכהה)

2. **הכירו את המרכז.** כל אריח הוא אפליקציה. לחיצה על אריח פותחת אותה בתוך המרכז. אפשר לשתף את הכתובת של מסך פתוח: היא מובילה בדיוק אליו.

3. **בדקו ש«קבצים» דולקת.** בלשכה חדשה «קבצים» דולקת מההתחלה, ויש לה אריח במרכז.
   אם מישהו כיבה אותה: פתחו את «ניהול אפליקציות», מצאו את «קבצים» והדליקו אותה. המסך מבצע את כל ההדלקה.

   מהמסוף, אותו דבר בשתי פקודות. הראשונה רושמת את ההחלטה, השנייה מעלה את האפליקציה:

   ```bash
   ./bbox apps enable drive
   ./bbox run
   ```

   מה תראו: אריח «קבצים» במרכז.

   ![«ניהול אפליקציות» עם השורה של «קבצים» והמתג שלה](TODO-shot: first-hour-2-app-management — «ניהול אפליקציות», השורה של «קבצים» עם המתג; שולחן עבודה 1440x900, ערכה בהירה וכהה)

4. **שימו קובץ ב«קבצים».** פתחו את האריח והעלו את הקובץ לתיקייה.

   מהמסוף:

   ```bash
   ./bbox drive put ./doc.pdf /מסמכים/
   ```

   מה תראו: הקובץ ברשימה של התיקייה.

   ![«קבצים» עם הקובץ שהועלה](TODO-shot: first-hour-3-drive-file — «קבצים» עם הקובץ שהועלה; שולחן עבודה 1440x900, ערכה בהירה וכהה)

5. **חברו את «בינה» למודל שפה.** פתחו את «חיבורים ומפתחות» ושמרו שם את המפתח שלכם, באחד משלושת החיבורים של הסוכן.

   ![«חיבורים ומפתחות» עם חיבור מפתח של מודל שפה של «בינה»](TODO-shot: first-hour-4-connections — «חיבורים ומפתחות», חיבור מפתח של מודל שפה; שולחן עבודה 1440x900, ערכה בהירה)

6. **בקשו מ«בינה» למצוא את הקובץ.** פתחו את האריח «עזריה» וכתבו, למשל: «מצאי לי את הקובץ doc.pdf בקבצים».

   «בינה» לומדת כל אפליקציה דולקת מהתדריך שלה. כש«קבצים» דולקת, הסוכן מקבל גם את התדריך שלה.

   מה תראו: תשובה עם הנתיב של הקובץ.

   ![«בינה» עונה עם הנתיב של הקובץ](TODO-shot: first-hour-5-bina-answer — שיחה ב«עזריה», התשובה עם הנתיב; שולחן עבודה 1440x900, ערכה בהירה וכהה)

   מהמסוף אפשר לבדוק את אותה תשובה בלי הסוכן:

   ```bash
   ./bbox drive find doc
   ```

## ניקוי

רוצים לכבות את «קבצים»? `./bbox apps disable drive`, ואחר כך `./bbox run`. הקבצים נשמרים.

## מה יש לכם עכשיו

לשכה עם כניסה אחת, אפליקציה דולקת, קובץ בתוכה, וסוכן שפועל בה.
