## Docker 28

כל ההתקנות של הלשכה מתקינות Docker 28.5.2 ונועלות אותו.

**שואלים את המנוע, לא את הגרסה.** נתב הקצה (`traefik` 3.3) מדבר עם המנוע כלקוח בגרסת API 1.24. מנוע שלא עונה ללקוח כזה משאיר את הנתב בלי אף נתיב: הוא עולה, מדווח שהוא תקין, וכל כתובת מחזירה 404, בלי הודעת שגיאה. ב-Docker 29 מגדירים `DOCKER_MIN_API_VERSION=1.24`, ואז זה עובד: Docker 29.3.1 עבר כך את בדיקת הבסיס.

- על macOS ועל Windows, הלשכה מתקינה Docker 28 משלה. אין מה לעשות.
- על לינוקס, בדקו את הגרסה לפני ההתקנה:

```bash
docker version
```

`./bbox install debian` בודק את הגרסה: אם מותקן Docker שאינו 28, הוא נעצר ואומר זאת. כדי להחליף אותו (הקונטיינרים נעצרים, הנתונים נשמרים):

```bash
BBOX_REPLACE_DOCKER=1 ./bbox install debian
```

## זיכרון ודיסק

- **Mac עם 8 GB:** נמדד. המכונה הווירטואלית מקבלת 5 GiB ו-4 מעבדים. ההרצה הראשונה החמה לקחה כחמש דקות, ו-33 מתוך 33 שירותים היו תקינים.
- **הנחיה לחבילת Mac עתידית:** במפרט של macOS כתוב 24 GB כמינימום ו-32 GB בנוח, לפי מגבלות הזיכרון של כל השירותים יחד.
- **שרת לינוקס, נמדד:** לשכה של 60 קונטיינרים רצה על 2 מעבדים ו-8 GB זיכרון עם swap, ותופסת כ-44 GB בדיסק. השאירו כ-60 GB פנויים (הערכה, לא מדידה). לשכה עם פחות אפליקציות צריכה פחות. על Windows לא נמדד מספר משלו.
- **בנייה ראשונה:** הלשכה בונה את האימג'ים בהרצה הראשונה. במחשב קטן זה לוקח 10 עד 15 דקות. ההרצות הבאות משתמשות במטמון.
- **אנדרואיד:** האפליקציה צריכה 10 GB פנויים בטלפון.

## Ubuntu 26.04

בליבה 7.0.0-42 ומעלה, `postgres` לא עולה בגלל AppArmor.
לבדוק:

```bash
./bbox apparmor status
```

לתקן (זה שינוי מדיניות של המחשב, ובעל המחשב מחליט עליו):

```bash
sudo ./bbox apparmor install
```

## מחשב נייד עם לינוקס

מחשב נייד יכול להתחמם, להירדם או לקפוא. `./bbox run` אומר זאת כשהוא מזהה סוללה. לבדוק:

```bash
./bbox host-power status
```
