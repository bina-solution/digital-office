## למה

הלשכה רצה על לינוקס, על macOS ועל Windows.
בכל מחשב: `git clone` של המאגר הציבורי, ופקודה אחת או שתיים.
מה ששונה הוא המנוע שמריץ את הקונטיינרים.

## לפני שמתחילים

קראו את [הדרישות](/he/start/requirements). הדרישה החשובה: Docker מגרסה 28. על לינוקס, ההתקנה מתקינה אותו בעצמה.

![כרטיס לכל מערכת: לינוקס, macOS, Windows, אנדרואיד — המיומנות, המחשב והפקודה](/diagrams/install-chooser-cards.svg)

## הבחירות

### לינוקס (Debian או Ubuntu)

- **מחשב:** שרת או מחשב עם Debian או Ubuntu.
- **מיומנות:** עבודה במסוף, `sudo`, ועריכת קובץ הגדרות.
- **הפקודות:** `./bbox install debian`, אחר כך `./bbox run`.
- [התקנה על לינוקס](/he/start/install/linux)

### macOS

- **מחשב:** Mac עם macOS 13 ומעלה. הלשכה מריצה מכונה וירטואלית משלה, בלי Docker Desktop ובלי הרשאות מנהל.
- **מיומנות:** עבודה במסוף. קובץ ההגדרות נוצר לבד בהרצה הראשונה.
- **הפקודה:** `./bbox run`.
- [התקנה על macOS](/he/start/install/macos)

### Windows

- **מחשב:** Windows עם WSL2. הלשכה מתקינה Docker משלה בתוך WSL, ולא משתמשת ב-Docker Desktop.
- **מיומנות:** שורת פקודה של `CMD` או PowerShell. אם WSL2 עוד לא מותקן, צריך צעד אחד עם הרשאות מנהל והפעלה מחדש.
- **הפקודות:** `bbox.cmd install windows`, אחר כך `bbox.cmd run`.
- [התקנה על Windows](/he/start/install/windows)

### אנדרואיד

קיים היום: קובץ APK בגרסת טיוטה, פחות מ-2 GB, שלא נמצא בחנות. העלייה הראשונה איטית בערך פי 20 מאשר על מחשב, כי המעבד מדומה. דף ההתקנה לאנדרואיד עוד לא נכתב.

### בעזרת סוכן

סוכן קוד שרץ במחשב שלכם יכול להריץ את ההתקנה: הפקודה האחת `curl -fsSL https://digital-office.co.il/install.sh | bash`, או הפלאגין של Claude. הסיסמה והכניסה הראשונה נשארות שלכם.

- [התקנה בעזרת סוכן](/he/start/agent-prompt)

## איך בודקים שזה עבד

בסוף כל דף התקנה כתוב איך בודקים. בכל המחשבים: `./bbox status` (על Windows `bbox.cmd status`) מראה את מצב הקונטיינרים.
