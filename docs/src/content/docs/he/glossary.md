## מילים

| מילה | באנגלית | מה זה |
|---|---|---|
| לשכה | office | מחשב אחד שמריץ את DGO, עם `.env` אחד. |
| DGO | Digital Office | הלשכה הדיגיטלית: מערכת ההפעלה של הלשכה. |
| המרכז | Console | המסך שמכיל את כל האפליקציות של הלשכה, כל אחת כאריח. |
| אריח | tile | אפליקציה כפי שהיא מופיעה במרכז. הכתובת שלו במרכז: `#/m/<id>`. |
| אפליקציה | app | תיקייה אחת עם `app.json` אחד. |
| שכבה | layer | 0 המהדר (`platform/`), 1 ו-2 הבסיס (`platform-base/`), 3 המוצרים (`apps/`). |
| הצהרה | declaration | `app.json` ו-`platform.state.yaml`: מה הלשכה אמורה להריץ. |
| מהדר | compiler | `platform/manager/reconcile.py`: קורא את ההצהרות ובונה את `.generated/`. |
| `.generated/` | | הפלט של המהדר. לא עורכים ולא שומרים ב-`git` ביד. |
| `bbox` | | הפקודה של הלשכה. על Windows: `bbox.cmd`. ‏`bbox help` מראה את כל הפקודות. |
| ארבעת הערוצים | four channels | מסך, פקודה, ממשק HTTP, זרם אירועים. |
| מנוע | engine | ה-Docker שמריץ את הלשכה. על macOS מכונה וירטואלית משלה, על Windows בתוך WSL. |
| `.env` | | קובץ ההגדרות והסודות של הלשכה. לא נכנס ל-`git`. |
| כניסה | sign-in | כניסה אחת לכל האפליקציות. בלשכה חדשה דרך `forward-auth` («זהות וכניסה»). |
| חיבור | connection | מפתח או כניסה לשירות חיצוני, שמור ב«חיבורים ומפתחות». |
| ניהול אפליקציות | App Management | המסך שמדליק ומכבה אפליקציות. |
| להדליק, לכבות | enable, disable | `bbox apps enable` ו-`bbox apps disable`. הנתונים נשמרים תמיד. |
| סוכן | agent | הסוכן של הלשכה, «בינה» (`bina-ds`). |
| תדריך | brief | `AGENT.md` של אפליקציה: מה שהסוכן לומד עליה. |
| מופע | instance | לשכה אחת משרתת כמה מופעים. |
| עדר | herd | כמה לשכות מקושרות שפועלות כעסק אחד. |
| קישור | link | חיבור בין שתי לשכות, דרך «הרחבת הלשכה» (`dgo-extend`). |
| הרחבת הלשכה | Office extension (`dgo-extend`) | האפליקציה שמקשרת לשכות. |
| מחשבים | Computers | האפליקציה שמכירה את מחשבי העדר. |
| קצה | edge | `traefik`: מקבל כל בקשה ומעביר אותה לאפליקציה. |
| שער | gate | בדיקה אוטומטית של המאגר, עם מספר (למשל G7). |
