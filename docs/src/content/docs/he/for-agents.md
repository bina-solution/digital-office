## למי הדף הזה

לסוכן קוד (או לאדם) שעובד בתוך תיקייה של הלשכה הדיגיטלית. הכללים כאן הם מה שהלשכה דורשת כדי לא להישבר בשקט.

## להתחיל

- אין עדיין לשכה במחשב? ההתקנה בפקודה אחת: `curl -fsSL https://digital-office.co.il/install.sh | bash`. מה היא עושה, ומה נשאר לאדם: [התקנה בעזרת סוכן](/he/start/agent-prompt).
- קובץ הכניסה של המאגר הוא `AGENTS.md`. קראו אותו קודם.
- `./bbox help` מראה כל פקודה של הלשכה, וכל פועל של כל אפליקציה.
- על Windows, כל פקודה היא `bbox.cmd` במקום `./bbox`.

## מה לעשות

1. **להפעיל את הלשכה רק דרך `bbox` או `./scripts/dc`.** השירותים נבנים מההצהרות לתוך `.generated/`.

2. **לשנות הצהרה, לא פלט.** מה שרץ נקבע ב-`apps/*/app.json` וב-`platform.state.yaml`. את `.generated/` לא עורכים ביד.

3. **להדליק ולכבות אפליקציות בפקודה של הלשכה:**

   ```bash
   ./bbox apps enable <app>
   ./bbox apps disable <app>
   ```

   הפקודה רק כותבת את ההחלטה. כדי שהיא תרוץ:

   ```bash
   ./bbox run
   ```

4. **לבדוק מול פלט אמיתי לפני שאומרים «גמור».**

   ```bash
   ./bbox status
   ./bbox verify
   ```

5. **לגבות לפני כל מחיקה.**

   ```bash
   ./bbox export
   ```

6. **להסביר פקודה מסוכנת לפני שמריצים אותה.** כל פקודה שמוחקת, מזיזה, עוצרת או כותבת קבצים, שירותים או נתונים: שורה אחת שאומרת מה היא עושה ומה עלול להישבר.

## מה לעולם לא

- **לא `docker compose` ישיר.** `compose.yml` מחזיק רק את הרשת המשותפת. פקודה ישירה מוצאת אפס שירותים ויוצאת בהצלחה, בלי לעשות דבר.
- **לא `docker compose -f apps/<app>/docker-compose.yml`.** זה פותח פרויקט שני עם אותם שמות קונטיינרים, וההרצה הבאה של `bbox run` נכשלת.
- **לא `docker cp` כפריסה.** השינוי חי רק עד שהקונטיינר נבנה מחדש, ו-`bbox run` בונה מחדש.
- **Docker: שואלים את המנוע, לא את הגרסה.** ההתקנות נועלות Docker 28.5.2. על Docker 29 צריך `DOCKER_MIN_API_VERSION=1.24`. בלי זה הנתב לא מנתב, בלי הודעת שגיאה.
- **לא להדפיס סודות.** `.env` מחזיק את כל הסודות של הלשכה ולא נכנס ל-`git`.
- **לא `./bbox reset` בלי שהבעלים ביקש.** הפקודה מוחקת את כל הנתונים.

## איך בודקים שהלשכה תקינה

```bash
./bbox status
./bbox verify
```

`bbox verify` יוצא עם קוד שאינו אפס כשמשהו שבור.
