# CLAUDE.md — project instructions for continuing the המרכז mockup

You are continuing a pixel-fidelity UI mockup of the **"המרכז / Business Center"** platform
(RTL Hebrew business suite). Read `context/HANDOFF.md` first — it has the full context and the
hard-won lessons. This file is the quick operating guide.

## The deliverable
`mockup/business-center-mockup.html` — one self-contained navigable HTML file, 54 screens.
Rebuild it with `node tooling/assemble.js` (bundles `tooling/frag/*.html` into `tooling/index.base.html`).

## Golden rules (do not regress these)
- **RTL sidebar is on the RIGHT.** The `.hm-side`/`.dv-rail` flex children must have a LOWER `order`
  than `.hm-main` so RTL flex-start puts them on the right. Sidebar width = **238px**.
- **Font stack** = `"Segoe UI",system-ui,-apple-system,"Noto Sans Hebrew","Assistant",Arial,sans-serif`.
  Install `fonts-noto-core` in the render env. Do NOT use Heebo.
- **Stat cards** = label on top, number below (`.stat:not(.stat-big){flex-direction:column-reverse}`).
- Hide `#navBtn` in any diff/verify render; keep it in the deliverable.
- Each screen is a full self-contained `<section class="screen" data-screen="ID">`; the shell markup is
  repeated per screen but styled from shared CSS in `index.base.html`. Follow `tooling/SPEC.md`.

## Verify a change
```bash
node tooling/assemble.js tooling/dist.html
python3 tooling/one.py <screen-id> <real-basename> <tag>   # prints DIFF %, writes diff_<tag>.png
```
Real screenshots: `reference/real-screenshots/<basename>.png`. Aim: match the real screenshot's exact
layout metrics, text/numbers, colors. The floor is ~5–6% (anti-aliasing + live data).
