# Code of conduct

DGO follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
we want everyone — whatever their experience, background or language — to be able to take part, and we expect
contributors and maintainers to treat each other with respect in issues, pull requests, discussions and anywhere they
speak for the project.

**To report a problem:** write to <hello@digital-office.co.il> with «conduct» in the subject. Reports are handled
confidentially, and the maintainers act on them as the Covenant's enforcement guidelines describe.
